# SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running. Slot 0 is
# expanded (main ROM 0-0, 4096 KB Extra-Mapper 0-1 for BIOS/DOS, MSX-MUSIC 0-2,
# Wi-Fi BIOS 0-3); SX2RES 2.8+ holds the 2048 KB mapper in 3-0, MegaSD in 3-2,
# slots 1-2 empty. Built from OCM-BIOS.DAT via make firmware (docs/MACHINES.md).
openmsx -machine OCM_SX-2_extramapper
disk hda
firmware machines/OCM_SX-2_extramapper.xml
# SX2RES keeps its game entry at 4040h of every segment of slot 3-0, where it
# starts PUSH AF / IN A,(0FDh) / PUSH AF / LD A,n. A restore writes the game's
# page 3 as captured, without SX2RES's hooks, so each image calls the entry
# itself, from T0, H.KEYI or a wrapper (docs/internals/service-and-resident.md, The resident program's
# call), and the build refuses an image with RAM in 3-0. The check puts PUSH
# AF / IN A,(0FDh) / PUSH AF / LD A,0 / POP AF / POP AF / RET there in openMSX.
# The capture variant without the 2048 KB mapper in 3-0 serves the games that
# keep a RAM page there.
resident 3-0 4040 F5 DB FD F5 3E 00 F1 F1 C9
variant sx2-extramapper-noram30
# KdL's sub-ROM writes its defaults to the clock chip at every boot, among them
# a text width of 80, and BASIC starts with it, where an MSX2 starts with 37.
# The image restores the captured width.
width 37
