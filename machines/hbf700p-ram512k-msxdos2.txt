# Sony HB-F700P (MSX2, 256 KB) with a 512 KB RAM cartridge, under MSX-DOS 2. The
# HB-F700P's 256 KB is a memory mapper, and its slot 0 is expanded. The cartridge is
# a memory mapper too, and MSX-DOS 2 takes the larger mapper.
openmsx -machine Sony_HB-F700P -ext ram512k -ext msxdos2
disk diska
variant hbf700p-msxdos2
