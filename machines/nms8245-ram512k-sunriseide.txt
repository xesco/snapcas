# Philips NMS 8245 (MSX2, 128 KB) with a 512 KB RAM cartridge and a Sunrise IDE. The
# NMS 8245's 128 KB is a memory mapper, and the RAM cartridge is a memory mapper
# too. The Sunrise IDE interface runs Nextor, which takes the larger mapper and
# leaves room for the images' segments.
openmsx -machine Philips_NMS_8245 -ext ram512k -ext SunriseIDE_Nextor
disk hda
