# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader at 9200h looks for RAM in page 0, then in page 1, by the slot
# register alone, keeps its value for RAM in pages 0 and 1 at F097h and the
# BASIC value at F09Eh, and puts BASIC's page 0 with the RAM's page 1 at F090h.
# Here BASIC and the RAM, the Extra-Mapper in 0-1, are both in slot 0, so the
# search takes SX2RES's mapper in 3-0 for page 0 and runs past slot 3 for page
# 1. The patch at 9204h skips the search with B = 50h and C = 55h, slot 0's
# subslot register for BASIC and for RAM in every page, so that the three
# values become subslot register values: 55h, 50h and 54h.
patch side1:2A DB A8 47 E6 F0 4F > 06 50 0E 55 18 20

# The loader's three routines at F08Eh, F095h and F09Ch, PUSH AF / LD A,n /
# OUT (0A8h),A / POP AF / RET, become NOP / LD A,n / LD (0FFFFh),A / RET, so
# that they write the values to slot 0's subslot register. Their callers do not
# read A afterwards. The game keeps two copies of these routines, at 9374h and
# DBF7h, for its later loads, and fills in their values from F000h and F001h.
# These get the same patch.
patch side1:DE F5 3E 00 D3 A8 F1 C9 > 00 3E 00 32 FF FF C9
patch side1:E5 F5 3E 00 D3 A8 F1 C9 > 00 3E 00 32 FF FF C9
patch side1:EC F5 3E 00 D3 A8 F1 C9 > 00 3E 00 32 FF FF C9

# The loader leaves the values for the game at F000h and F001h, from F097h and
# F09Eh. The game selects BASIC's page 0 with F001h's bits before each later
# load, which the tape service serves after the restore. The service's entry
# selects page 0 in slot 0 by the slot register alone, so page 0 must keep the
# Extra-Mapper's subslot. LD A,(0F09Eh) at 928Ch becomes LD A,(0F097h), so
# that F001h holds 55h and the game's loads keep RAM in page 0.
patch side1:B2 3A 9E F0 > 3A 97 F0

# The game's image has no call of SX2RES, and the game writes over the BIOS's
# slot routines and tables in page 3. A routine at BD40h, in FFh bytes of page 2
