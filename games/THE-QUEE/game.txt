# The game's start calls 0115h, which is no BIOS entry. It is the second byte of
# the jump table's entry at 0114h. An MSX1's bytes there run on into TAPIN, which
# waits 7 seconds at the tape's end and returns. An MSX2's bytes there jump into
# RAM, the game falls out of its start, and BASIC stops at "Syntax error in 10".
# The patch makes the call three NOPs.
patch side1:2FF1 CD 15 01 > 00 00 00
