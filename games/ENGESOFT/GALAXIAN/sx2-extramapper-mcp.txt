# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs without the 2048 KB mapper in 3-0, which the game's RAM would
# otherwise take, and SX2RES holds it.
capture sx2-extramapper-noram30

# The ROM image never reads the tape again: the rest of the tape is the next
# game's. Without the tape service the restorer keeps the BIOS in page 0, in
# another subslot of DOS's mapper's slot.
service no

# The loader's RAM search at DE43h tries the slot IDs 3, 2 and 1 only, never an
# expanded slot. Here the RAM is in slot 0-1, ID 84h. The patch stores 84h as
# the slot of pages 0 and 1, at DD3Eh and DD3Fh, and returns.
patch side1:B2E7 21 10 00 22 3A DD 3E 03 32 > 3E 84 32 3E DD 32 3F DD C9

# After the copy of the ROM image to page 1, the loader gives page 1 slot ID
# 00h again, by XOR A at DD44h, for BASIC's ROM. Here ID 00h changes only the
# slot register and leaves page 1 on the RAM, because slot 0 is expanded. The
# patches put LD A,80h / LD H,40h / JR 0DD47h, the ROM's ID 80h, in the NOPs at
# DD34h, and make the loader return there in place of DD44h.
patch side1:B1D8 00 00 00 00 00 00 > 3E 80 26 40 18 0D
patch side1:B1B9 21 44 DD > 21 34 DD
