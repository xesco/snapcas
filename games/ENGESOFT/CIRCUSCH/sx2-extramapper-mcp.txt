# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs without the 2048 KB mapper in 3-0, which the game's RAM would
# otherwise take, and SX2RES holds it.
capture sx2-extramapper-noram30

# The ROM image never reads the tape again: the rest of the tape is the next
# game's. Without the tape service the restorer keeps the BIOS in page 0, in
# another subslot of DOS's mapper's slot.
service no

# Engesoft's loader gives page 1 the slot of page 3 by the slot register alone,
# copies the ROM image to page 1 and starts it. Here the BIOS and the RAM are
# both in slot 0, in subslots 0 and 1, so page 1 keeps the ROM. The patch writes
# 54h to slot 0's subslot register in place of that code: the BIOS in page 0 and
# RAM in pages 1 to 3.
patch side1:456A DB A8 CB 7F 28 02 CB DF CB 77 28 02 CB D7 D3 A8 > 3E 54 32 FF FF 00 00 00 00 00 00 00 00 00 00 00
