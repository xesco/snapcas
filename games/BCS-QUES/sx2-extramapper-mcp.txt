# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30, without the 2048 KB mapper in
# 3-0. On sx2-extramapper-mcp itself the snapshot keeps a RAM page in 3-0, which
# SX2RES holds.
capture sx2-extramapper-noram30

# The game resets the machine 119.37 seconds after the load command, to start
# its ROM image, and the BIOS's boot then sets up page 3 again, over the image's
# call of SX2RES. At 122.6 seconds the boot is done and the ROM image runs, so
# the snapshot at that moment keeps the call.
snapshot at 122.6

# The ROM image keeps the VDP's frame interrupt off and writes RET in H.KEYI,
# so the image's call of SX2RES from H.KEYI never runs. It reads the joystick
# with GTSTCK once a frame, at 41A7h in its title and at 4A61h in play. A
# routine at A000h, in FFh bytes after the ROM image, calls the image's
# routine at FD29h, which calls SX2RES with the BIOS's CALSLT, and jumps to
# GTSTCK. It runs the call on a stack of its own below BFF0h, because the
# game's stack at E3B9h is shallow and its data lies below it, and keeps IX,
# IY, the alternate registers and the interrupt flag, which the BIOS's slot
# routines change.
patch page2:2000 FF FF FF FF FF FF FF FF FF FF > F5 ED 73 FE BF 31 F0 BF ED 57
patch page2:200A FF FF FF FF FF FF FF FF FF FF > F5 DD E5 FD E5 D9 C5 D5 E5 D9
patch page2:2014 FF FF FF FF FF FF FF FF FF FF > 08 F5 08 CD 29 FD 08 F1 08 D9
patch page2:201E FF FF FF FF FF FF FF FF FF FF > E1 D1 C1 D9 FD E1 DD E1 F1 E2
patch page2:2028 FF FF FF FF FF FF FF FF FF FF > 2B A0 FB ED 7B FE BF F1 C3 D5
patch page2:2032 FF > 00

# Both calls of GTSTCK call the routine instead.
patch page1:1A7 CD D5 00 > CD 00 A0
patch page1:A61 CD D5 00 > CD 00 A0
