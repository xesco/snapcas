# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs without the 2048 KB mapper in 3-0, which the game's RAM would
# otherwise take, and SX2RES holds it.
capture sx2-extramapper-noram30

# The ROM image never reads the tape again. Without the tape service the
# restorer keeps the BIOS in page 0, in another subslot of DOS's mapper's slot.
service no

# The loader looks for RAM in page 1 by the slot register alone. Here the BIOS
# and the RAM are both in slot 0, in subslots 0 and 1, so the search never finds
# RAM. Each patch writes 54h to slot 0's subslot register, the BIOS in page 0
# and RAM in pages 1 to 3, and jumps past the search: to the copy of the ROM
# image to page 1, or to the start of the image. The ROM image finds its own
# slot from SLTTBL's entry for slot 0 at FCC5h, which still held BASIC's 50h, so
# it selected slot 0-0 in page 2 by ID 80h and the machine reset when play
# started. The second patch also writes 54h to FCC5h, in the search's dead
# bytes, before its jump to the start of the image.
patch side1:4146 DB A8 32 02 D1 C6 10 32 > 3E 54 32 FF FF C3 3B D0
patch side1:826E DB A8 C6 10 32 01 D1 C6 > 3E 54 32 FF FF 32 C5 FC
patch side1:8276 F4 32 00 > C3 38 D0

# The first binary then gives page 1 its slot again from the slot register's
# old value. The patch writes 50h to the subslot register, the BIOS in pages 0
# and 1, in place of that code.
patch side1:418C 3A 02 D1 D3 A8 > 3E 50 32 FF FF

# When play starts the game writes its own hook into H.KEYI, a jump to 42B8h,
# at 4314h, which ends the image's calls of SX2RES. The patches make it write
# a jump to FD09h, in the zeros of SLTWRK, which calls the image's routine at
# FD29h and jumps to 42B8h. That hook takes the registers from the stack.
patch side1:458 B8 42 > 09 FD
patch page3:3D09 00 00 00 00 00 00 > CD 29 FD C3 B8 42
