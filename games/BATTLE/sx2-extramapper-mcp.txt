# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# After the snapshot the game puts its own routines into H.KEYI, over the
# image's call of SX2RES, which then stops: JP 41A5h copied from 4192h and JP
# 445Eh copied from 44D8h. The image's wrappers call SX2RES and jump to each
# routine.
rescall 41A5 445E

# The game installs the wrappers' addresses instead, FD00h and FD06h after resb
# at FCC9h, as build.txt's resvector gives them, one patch for each writer.
patch page1:193 A5 41 > 00 FD
patch page1:4D9 5E 44 > 06 FD

# To turn its routine off the game fills H.KEYI with RET, from 4195h, and the
# calls stop. The game's routine replaces the BIOS's interrupt routine, so with
# it off the BIOS's routine runs alone. The patch writes JP FCC9h there instead,
# a jump to the image's resb, which calls SX2RES and returns, as the image's
# H.KEYI does at the restore.
patch page1:195 21 9A FD 11 9B FD 36 > F3 21 C9 FC 22 9B FD
patch page1:19C C9 01 02 00 F3 ED B0 > 3E C3 32 9A FD 00 00
