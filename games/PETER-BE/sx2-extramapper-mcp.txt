# and SX2RES running.

# The image has no call of SX2RES: the game uses the zeros in page 3 where the
# image's code for the call goes, or has no room there that the check allows. A
# routine at 2E60h, as in Knight Lore's file for this machine, in zeros of page
# 0 that the game leaves alone in a minute of play with keys, uses no BIOS
# routine. It keeps all the registers and the interrupts, selects slot 3's
# subslot 0 in page 1 with slot 3's subslot register, selects slot 3 in page 1
# with the slot register, and calls SX2RES's entry at 4040h when it starts F5h

# / CALL 2E60h / LD SP,(2ECEh) / JP 1526h: the game's stack is in page 1, which
# the routine gives to SX2RES, so the call runs on a stack in zeros below 1700h.
