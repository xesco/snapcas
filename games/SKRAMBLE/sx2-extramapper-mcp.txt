# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader at C000h looks for RAM in pages 1 and 0 by the slot register alone,
# keeps BASIC's slot register value at C301h and the RAM's at C302h, and swaps
# between them by the slot register again. Here the BIOS and the RAM share slot
# 0, so the search finds no RAM and the loader stops at "Sorry, not enough RAM".
# The patches skip the search, and make each swap a write of slot 0's subslot
# register instead: 55h for RAM in every page, 50h for BASIC.

# The search, at C02Ch, becomes LD A,55h / LD (0FFFFh),A / JP 0C0D6h, the store
# of the RAM's value after it.
patch side1:27A AF 32 F6 C3 3A F6 C3 CB > 3E 55 32 FF FF C3 D6 C0

# The copy of each block to RAM, at C173h. The byte 57h at C178h stays, as the
# loader checks its own code by that byte.
patch side1:3C1 3A 02 C3 0E A8 57 ED 51 > 3E 55 32 FF FF 57 00 00

# The return to BASIC at C2DCh, and the game's CALSLT at C2E2h, which selects
# BASIC for the call and the RAM after it.
patch side1:52A 3A 01 C3 D3 A8 > 3E 50 32 FF FF
patch side1:532 3A 01 C3 D3 A8 > 3E 50 32 FF FF
patch side1:540 3A 02 C3 D3 A8 > 3E 55 32 FF FF

# The routine at 0D9Ch counts with INC (HL) after LD HL,(0127h), where it means
# LD HL,0127h: the two bytes at 0127h hold FFh, so the counter is the byte at
# FFFFh. Here FFFFh is slot 0's subslot register, and the routine's
# LD (HL),0FEh deselects the RAM. The patch makes the instruction LD HL,0127h,
# so the counter is the byte at 0127h, as on sx2.
patch side1:1360 2A 27 01 > 21 27 01

# The loader keeps the exclusive OR of each block's 1024 bytes and compares it
# with the byte after the block. The patch gives that byte the value for the
# changed block, 6Dh XOR 0Bh.
patch side1:16C2 6D > 66

# The game runs on the BIOS's interrupt routine, with the BIOS in page 0, but
# the snapshot keeps its RAM page 0, so the image's T0 makes no call of SX2RES,
# and H.KEYI holds RET. The image's wrapper calls SX2RES through the tape
# service's entry code and jumps to the RET at FD9Dh, in H.KEYI after the patch
# below. sub0 takes FCC9h, so the wrapper goes to FB03h, in the work area of an
# RS-232C interface, which stays at zeros on the SX-2, which has none.
rescall FD9D
rescode FB03

# H.KEYI calls the wrapper: CALL 0FB03h / RET.
patch page3:3D9A C9 C9 C9 > CD 03 FB

# The build writes the wrapper's 17 bytes but, with the tape service, does not
# list them for the check, which then finds them changed. This patch changes
# nothing and lists them.
patch page3:3B03 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 > 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
