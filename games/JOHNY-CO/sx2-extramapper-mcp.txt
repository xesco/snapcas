# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-3-0.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The binary c1 (CB20h) copies g1 into page 1 and installs the launcher at B5A4h,
# selecting page 1 RAM and BASIC through RSLREG/WSLREG (primary slot register
# alone). Here both the BIOS and RAM are in slot 0 (subslots 0 and 1), so page 1
# stayed on BASIC ROM and g1 was never copied to RAM. Write slot 0's subslot
# register instead: 54h for RAM in pages 1 to 3 (and SLTTBL at FCC5h in the
# launcher), and 50h for BASIC's ROM in pages 0 and 1.
patch side1:163 3A 9C E0 CD 3B 01 C9 > 3E 50 32 FF FF 00 C9
patch side1:16A CD 38 01 32 9C E0 > 3E 54 32 FF FF C9
patch side1:1A0 CD 38 01 5F E6 30 1F 1F E6 > 3E 54 32 FF FF 32 C5 FC C9
