# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# At each new hand, at 95C7h, the game clears four tables of 1158 bytes that end
# at FCFDh, over FCC9h, where the build puts the image's call of SX2RES and its
# wrapper for the game's interrupt routine, and over SLTATR and SLTWRK, where
# the build looks for the call's stack. Put the code and the stack in the unused
# C9h BIOS hook area at FF01h..FFA7h.
rescode FF01
resstack FF40
