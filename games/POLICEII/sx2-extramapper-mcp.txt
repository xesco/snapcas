# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30, without the 2048 KB mapper in
# 3-0. On sx2-extramapper-mcp itself the snapshot keeps a RAM page in 3-0, which
# SX2RES holds.
capture sx2-extramapper-noram30

# The game runs on the BIOS's interrupt routine at the snapshot, and the image
# calls SX2RES from H.KEYI. Then the game puts its own routine at 0038h in its

# file for this machine, in zeros of page 2 that the game leaves alone in a
# minute of play with keys, uses no BIOS routine. It keeps all the registers and
# the interrupts, selects slot 3's subslot 0 in page 1 with slot 3's subslot
# register, selects slot 3 in page 1 with the slot register, and calls SX2RES's
# entry at 4040h when it starts F5h DBh. Then it gives both registers back. At
