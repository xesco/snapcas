# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader at 9000h looks for RAM in pages 0 and 1 by the slot register alone,
# keeps BASIC's value at F30Fh and the RAM's at F310h, and selects them later
# by the slot register again. Here the BIOS and the RAM share slot 0, so the
# search finds the 2048 KB mapper in 3-0, which SX2RES holds, in page 0, and no
# RAM in page 1. The first patch skips the search and writes 55h, RAM in every
# page, to slot 0's subslot register, where the loader selects the RAM; its
# third byte, after the jump, keeps the block's XOR, which the loader checks.
# The second makes the loader's return to BASIC write 50h there.
patch side1:1EB8 CD 23 90 21 00 50 0E 04 CD 23 90 7A 32 10 F3 D3 A8 > 18 09 07 21 00 50 0E 04 CD 23 90 3E 55 32 FF FF 00
patch side1:1F12 3A 0F F3 D3 A8 > 3E 50 32 FF FF

# The second block selects the RAM by F310h too, at E40Ch, before it starts the
# game at D7B4h. The patch writes 55h to slot 0's subslot register, and the
# next changes the block's last byte, its XOR.
patch side1:BA37 3A 10 F3 D3 A8 > 3E 55 32 FF FF
patch side1:C5FB 83 > 78

# At 8B08h the game uses LD B,80h / LD E,L / LD D,H / LDIR from 8C59h as a
# busy-wait delay, copying 8C59h..0C58h onto itself. That triggers page 3
# write watches over the call of SX2RES and writes inverted FFFFh back to
# slot 0's subslot register at FFFFh. Lower B to 30h so the loop stays in
# page 2 (8C59h..BC58h).
patch page2:B09 80 > 30
