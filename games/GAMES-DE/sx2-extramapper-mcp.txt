# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The block GCODE looks for RAM in pages 0 and 1 by the slot register alone,
# finds none here, where the BIOS and the RAM share slot 0, and stops at NO
# RAM AT PAGE0/1. The first patch replaces the search: it writes 55h, the RAM
# in every page, to slot 0's subslot register for the copy to 0038h, and
# stores 00h, the slot register's value here, as the result at A002h. The
# second gives BASIC back with 50h, and the third starts the game at 1000h
# with 55h, in place of the slot register's values at A001h and A002h.
patch side1:3BF8 E6 F0 4F 16 01 21 00 00 CD 79 > 3E 55 32 FF FF AF 32 02 A0 18
patch side1:3C02 93 > 0C
patch side1:3C1E 3A 01 A0 D3 A8 > 3E 50 32 FF FF
patch side1:3C5F 3A 02 A0 D3 A8 > 3E 55 32 FF FF
