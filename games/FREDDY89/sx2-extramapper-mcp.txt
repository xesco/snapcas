# The game runs with its interrupts off and no BIOS in page 0, so the image
# has no call of SX2RES from an interrupt. The call routine res3 goes to F900h,
# in zeros of page 3 that the game leaves alone in a minute of play with keys,
# and the game's own code calls it.

# The game tests each key with its routine at ED3Bh, in its title and in play,
# thousands of times a second, and never reads the VDP's status. A routine at

# stack of its own below D8F0h, because the game's stack is in page 1, which
# res3 selects for SX2RES. Then it does the instructions that the next patch
# replaces, PUSH BC / PUSH AF / SRA A, and jumps back to ED3Fh.
