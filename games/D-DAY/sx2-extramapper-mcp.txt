# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The game runs without interrupts, so the image's call of SX2RES from H.KEYI
# never runs, and in play it copies a table over FD00h to FE7Fh, where the
# image's routine for the call is. A routine at FC4Ch, in BASIC's TRPTBL, which
# only BASIC's interrupt routine reads, keeps all the registers, selects slot 3
# in page 1 with the slot register alone, where the image's header gives slot 3
# the subslot of SX2RES, and calls SX2RES's entry at 4040h when it starts F5h
# DBh. Then it gives the slot register back. It uses no BIOS routine.
patch page3:3C4C 00 00 00 00 00 00 00 00 00 00 > F5 C5 D5 E5 DD E5 FD E5 D9 C5
patch page3:3C56 00 00 00 00 00 00 00 00 00 00 > D5 E5 08 F5 08 DB A8 F5 E6 F3
patch page3:3C60 00 00 00 00 00 00 00 00 00 00 > F6 0C D3 A8 3A 40 40 FE F5 20
patch page3:3C6A 00 00 00 00 00 00 00 00 00 00 > 08 3A 41 40 FE DB CC 40 40 F1
patch page3:3C74 00 00 00 00 00 00 00 00 00 00 > D3 A8 08 F1 08 E1 D1 C1 D9 FD
patch page3:3C7E 00 00 00 00 00 00 00 00 > E1 DD E1 E1 D1 C1 F1 C9

# An entry at FC86h reads the VDP's status register 0, which the game never
# reads, calls the routine above when its bit 7 shows a new frame, so at most
# once a frame, and jumps to the BIOS's LDIRVM.
patch page3:3C86 00 00 00 00 00 00 00 00 00 00 > F5 DB 99 07 30 03 CD 4C FC F1
patch page3:3C90 00 00 > C3 5C

# The routine at 41C9h copies the game's screen to the VRAM with twelve LDIRVM,
# many times a second, in the title and in play. Its first LDIRVM calls the
# entry at FC86h.
patch page1:1DB CD 5C 00 > CD 86 FC

# In play the game copies a table over FD00h to FE7Fh, over the default call of SX2RES.
# Put the call routine and its stack in the unused C9h BIOS hook area.
rescode FF01
resstack FF50
