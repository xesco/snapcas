# The loader, and its copy in the game's block at 4000h, pushes a trampoline at
# FC98h: LD C,0A8h / OUT (C),L / EXX / CALL 00E1h / EXX / OUT (C),H / RET, with
# H the slot register and L the same with slot 0 in page 0, to reach the BIOS
# from its RAM in page 0. Here the BIOS and the RAM are both in slot 0, in
# subslots 0 and 1, so the slot register cannot swap them. The patches make the
# trampoline LD (HL),54h / EXX / CALL 00E1h / EXX / LD (HL),55h / RET, with HL
# = FFFFh, slot 0's subslot register: the BIOS in page 0, then RAM in every
# page again. The restore is a constant because the loader keeps each byte in
# C. The caller's IN A,(0A8h) / LD H,A / AND 0FCh / LD L,A becomes LD HL,0FFFFh
# / LD A,n, where n keeps the XOR by which the loader checks the block.
