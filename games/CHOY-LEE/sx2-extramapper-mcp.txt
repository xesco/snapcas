# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader's `slots` RAM search finds the RAM in 0-1 and leaves slot 0's
# subslot register at 55h, but its result and BASIC's slot register value are
# both 00h here, where the BIOS and the RAM share slot 0, so each later switch
# by the slot register alone does nothing. The patches skip the search and make
# each use of its stored values a write of slot 0's subslot register instead:
# 55h for RAM in every page, 54h for RAM in pages 1 to 3, 50h for BASIC.
patch side1:159 3A D1 D7 D3 A8 > 3E 55 32 FF FF
patch side1:169 3A D2 D7 D3 A8 > 3E 50 32 FF FF
patch side1:171 3A D1 D7 D3 A8 > 3E 55 32 FF FF
patch side1:181 3A D2 D7 D3 A8 > 3E 50 32 FF FF
patch side1:189 3A D1 D7 D3 A8 > 3E 55 32 FF FF
patch side1:246 47 08 78 E6 > 4F 08 18 78
patch side1:2CC 3A FF FF 2F > 3E 54 00 00

# The game runs without interrupts, so the image has no call of SX2RES. The
# rescode line puts the image's call routine at E7F0h, in zeros of page 3 that
# the game leaves alone, and the rescall line gives it a wrapper at E81Dh that
# calls SX2RES and jumps to the game's routine at 217Fh.
rescode E7F0
rescall 217F

# The routine at 28D0h, about 15 times a second in the title and in play, calls
# the routine at 217Fh. It calls the wrapper in place of that routine.
patch page0:28DD CD 7F 21 > CD 1D E8

# The game writes FD5Ch to FD6Ah in SLTWRK from 2962h, over res3's default stack
# at FD5Bh. Put the stack at E830h, in the same zero area after rescode.
resstack E830
