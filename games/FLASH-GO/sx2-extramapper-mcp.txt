# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The loader at 832Ch looks for RAM in pages 0 and 1 by the slot register
# alone, finds none here, where the BIOS and the RAM share slot 0, and waits
# in JR $. It keeps the original value and the one it found in its routines
# at 83FDh, BASIC, and 8402h, the RAM. The first patch skips the search and
# puts in its place a routine that writes 50h, BASIC, to slot 0's subslot
# register, where the routine at 83FDh jumps. The routine at 8402h writes
# 55h, the RAM in every page, without its DI: its one caller runs with the
# interrupts off.
patch side1:163 CD BB 83 > 00 00 00
patch side1:1D5 F3 DB A8 32 FE 83 > 3E 50 32 FF FF C9
patch side1:217 3E A0 D3 A8 C9 > C3 BB 83 00 00
patch side1:21C F3 3E AA D3 A8 C9 > 3E 55 32 FF FF C9

# The loader passes the two values to the game at FDFBh and FDFCh. The patch
# stores 00h, the slot register's value here, in both, and the game's
# selections by them become writes of slot 0's subslot register: 55h for the
# RAM at FDFBh, 50h for BASIC at FDFCh.
patch side1:176 3A 04 84 32 FB FD 3A FE 83 > AF 00 00 32 FB FD 00 00 00
patch side1:1FF4 3A FC FD D3 A8 > 3E 50 32 FF FF
patch side1:200D 3A FB FD D3 A8 > 3E 55 32 FF FF
patch side1:24BB 3A FB FD D3 A8 > 3E 55 32 FF FF
patch side1:26FF 3A FC FD D3 A8 > 3E 50 32 FF FF
patch side1:278F 3A FB FD D3 A8 > 3E 55 32 FF FF
patch side1:2797 3A FC FD D3 A8 > 3E 50 32 FF FF
patch side1:27B4 3A FC FD D3 A8 > 3E 50 32 FF FF

# The game sets its stack at the top of memory, with LD SP,0000h in three
# places. Its first push writes FFFFh, which is slot 0's subslot register
# here, and the write deselects the RAM. An MSX2+'s BIOS also keeps its copies
# of VDP registers 23 and 25 to 27 in FFF6h and FFFAh to FFFCh, and the main
# ROM's slot at FFF7h. The patches set the stack below all of them, at FFE7h.
patch side1:1D70 31 00 00 > 31 E7 FF
patch side1:1D8A 31 00 00 > 31 E7 FF
patch side1:2728 31 00 00 > 31 E7 FF

# In play the game takes the interrupt in mode 2, through a jump at FDFDh that
# the routine at 9320h writes after the snapshot, so the image has no call of
# SX2RES. The image's wrapper at FCC9h, before the tape service's entries, calls
# SX2RES and jumps to the game's interrupt routine at 97DBh.
rescall 97DB

# The routine at 9320h writes the wrapper's address into the jump at FDFDh in
# place of the game's interrupt routine, so the wrapper runs at each interrupt,
# 60 times a second.
patch page2:1331 21 DB 97 > 21 C9 FC
