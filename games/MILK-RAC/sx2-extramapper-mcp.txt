# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The loader at 82ADh looks for RAM in pages 0 and 1 by the slot register
# alone, finds none here, where the BIOS and the RAM share slot 0, and waits
# in JR $. The first patch skips the search. Its code then holds four routines
# that write slot 0's subslot register: 50h, BASIC, 50h with EI, 55h, the RAM
# in every page, with DI, and 55h. The loader's own routines at 8384h and
# 838Ah jump to the second and third, and its loop's selections, LD A,n / OUT
# (0A8h),A, call the first, before TAPIN, and the fourth, for the store.
patch side1:246 CD 30 83 > 00 00 00
patch side1:1C9 F3 DB A8 32 85 83 E6 F0 4F F6 > 3E 50 32 FF FF C9 3E 50 32 FF
patch side1:1D3 0F CD 50 83 79 F6 0A CD 50 83 > FF FB C9 F3 3E 55 32 FF FF C9
patch side1:1DD 79 F6 05 CD 50 83 > 3E 55 32 FF FF C9
patch side1:21D 3E A0 D3 A8 FB C9 > C3 36 83 00 00 00
patch side1:223 F3 3E AA D3 A8 C9 > C3 3D 83 00 00 00
patch side1:185 3E A0 D3 A8 > CD 30 83 00
patch side1:192 3E AA D3 A8 > CD 44 83 00
