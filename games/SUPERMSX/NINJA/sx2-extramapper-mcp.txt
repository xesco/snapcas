# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Super MSX's loader `slots` finds RAM by the slot register alone, keeps BASIC's
# slot register value at FFFDh and the RAM's at FFFEh, and selects them later by
# the slot register again. Here the BIOS and the RAM share slot 0, so both
# values are 00h and each switch does nothing. The patches skip the search and
# make each use of the two values a write of slot 0's subslot register
# instead: 50h for BASIC and 55h for RAM in every page.
patch side1:11498 47 08 78 E6 > 4F 08 18 78
patch side1:11514 20 DA > 18 0B
patch side1:115F8 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:1160D 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:11649 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:1167A 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:16EAA 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:16EBE 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:16EF3 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:16EFB 3A FE FF D3 A8 > 3E 55 32 FF FF

# At once after the end of the load the game writes page 3 from FD29h on,
# over the image's call of SX2RES. The snapshot comes after that, at 175
# seconds, where the game runs.
snapshot at 175

# The game runs with its interrupts off and no BIOS in page 0, so the image
# has no call of SX2RES from an interrupt. The call routine res3 goes to D330h,
# in zeros of page 3 that the game leaves alone in a minute of play with keys,
# and the game's own code calls it.
rescode D330

# Each pass of the game's main loop ends with a delay at BFFBh, LD BC,07B7h
# and a count down, about 14 ms. A routine at AFB0h, in zeros of page 2 that
# the game leaves alone, calls res3 at D330h on a stack of its own below B04Ch,
# so that SX2RES does not take the 50 bytes below the game's stack in page 0,
# then does LD BC,07B7h and returns.
patch page2:2FB0 00 00 00 00 00 00 00 00 00 00 > F5 ED 73 4E B0 31 4C B0 CD 30
patch page2:2FBA 00 00 00 00 00 00 00 00 00 00 > D3 ED 7B 4E B0 F1 01 B7 07 C9

# The delay's LD BC,07B7h calls the routine at AFB0h.
patch page2:3FFB 01 B7 07 > CD B0 AF

# In play the main loop no longer runs that delay. Each frame of play ends at
# 959Fh with CALL 0C210h. A second routine at AFD0h calls res3 the same way
# and jumps to C210h.
patch page2:2FD0 00 00 00 00 00 00 00 00 00 00 > F5 ED 73 4E B0 31 4C B0 CD 30
patch page2:2FDA 00 00 00 00 00 00 00 00 00 > D3 ED 7B 4E B0 F1 C3 10 C2

# That call calls the routine at AFD0h.
patch page2:159F CD 10 C2 > CD D0 AF
