# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Super MSX's loader `slots` finds RAM by a search that leaves slot 0's subslot
# register at 55h, RAM in page 0, when it returns with EI, so the load stopped
# right after it. It keeps BASIC's slot register value at FFFDh and the RAM's
# at FFFEh, and selects them later by the slot register again. Here the BIOS
# and the RAM share slot 0, so both values are 00h and each switch does
# nothing. The patches skip the search and make each use of the two values a
# write of slot 0's subslot register instead: 50h for BASIC and 55h for RAM in
# every page.
patch side1:EEFA 47 08 78 E6 > 4F 08 18 78
patch side1:EF76 20 DA > 18 0B
patch side1:F05A 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:F06F 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:F0AB 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:F0DC 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05

# The two copies of the game's pages 0 and 1, at 8700h, select the RAM with
# LD A,55h / LD (0FFFFh),A. After the LDIR, AND 0F0h leaves 50h in A, and
# DEC BC / LD (BC),A writes it to FFFFh: BASIC again. The loader checks each
# block by the exclusive OR of its bytes, so the NOP after the RET takes the
# change too.
patch side1:F122 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:F132 E6 F0 D3 A8 > E6 F0 0B 02
patch side1:F137 00 > 6B
patch side1:1324C 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:1325C E6 F0 D3 A8 > E6 F0 0B 02
patch side1:13261 00 > 6B

# The block that selects BASIC for DISSCR and LDIRVM, and then the RAM. A byte
