# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Super MSX's loader `slots` finds RAM by the slot register alone, keeps BASIC's
# slot register value at FFFDh and the RAM's at FFFEh, and selects them later by
# the slot register again. Here the BIOS and the RAM share slot 0, so both
# values are 00h and each switch does nothing. The patches skip the search and
# make each use of the two values a write of slot 0's subslot register
# instead: 50h for BASIC and 55h for RAM in every page.
patch side1:11689 47 08 78 E6 > 4F 08 18 78
patch side1:11705 20 DA > 18 0B
patch side1:117E9 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:117FE 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:1183A 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:1186B 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:118B1 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:118C1 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:159DB 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:159EB 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:19B05 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:1B42F 3A FE FF D3 A8 > 3E 55 32 FF FF

# The game runs without interrupts, so nothing calls SX2RES. The game's code
# fills page 3 from F000h, so the image's code for the call, its call routine
# res3 and its wrapper at E02Dh, which calls res3 and jumps to a RET at E053h,
# goes to E000h, in zeros from D92Ch to EEFFh that the game leaves alone.
rescode E000
rescall E053

# Two entries at E040h, in the same zeros. The first counts its calls in the
# byte at E05Bh and calls the wrapper at every 256th; the second calls it each
# time. Each then does the instructions that its call replaces and returns.
patch page3:2040 00 00 00 00 00 00 00 00 00 00 > F5 3A 5B E0 C6 01 32 5B E0 30
patch page3:204A 00 00 00 00 00 00 00 00 00 00 > 03 CD 2D E0 F1 DB AA E6 F0 C9
patch page3:2054 00 00 00 00 00 00 00 > CD 2D E0 21 B8 0B C9

# The routine at 7107h tests a key, and the title, the menus and the game's loop
# call it in their key scans, about 12000 times a second. It calls the first
# entry in place of IN A,(0AAh) / AND 0F0h.
patch page1:310E DB AA E6 F0 > CD 40 E0 00

# The game's delay at 76F5h waits B times about 22 ms. Each of them calls the
# second entry in place of LD HL,0BB8h.
patch page1:36F7 21 B8 0B > CD 54 E0
