# The game waits by copying C000h to FFFBh onto itself 50 times, with LD
# BC,3FFCh / LD HL,0C000h / LD DE,0C000h / LDIR at EA80h. The copy writes the
# same bytes, but it writes over the call of SX2RES at FD29h, so the check

# 1% as long and leaves FCC9h on alone.
