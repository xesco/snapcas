# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Super MSX's loader `slots` finds RAM by a search that leaves slot 0's subslot
# register at 55h, RAM in page 0, when it returns with EI, so the load stopped
# right after it. It keeps BASIC's slot register value at FFFDh and the RAM's
# at FFFEh, and selects them later by the slot register again. Here the BIOS
# and the RAM share slot 0, so both values are 00h and each switch does
# nothing. The patches skip the search and make each use of the two values a
# write of slot 0's subslot register instead: 50h for BASIC and 55h for RAM in
# every page.
patch side1:1888A 47 08 78 E6 > 4F 08 18 78
patch side1:18906 20 DA > 18 0B
patch side1:189EA 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:189FF 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:18A3B 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:18A6C 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05

# The block at 87E0h selects BASIC for DISSCR and LDIRVM, and then the RAM,
# with LD A,(0FFFDh) or (0FFFEh) / OUT (0A8h),A. Both write slot 0's subslot
# register instead. The loader checks each block by the exclusive OR of its
# bytes, so a NOP after the block's RET, at 87FAh, takes the change too.
patch side1:20B95 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:20BA9 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:20BAF 00 > 06

# The game runs without interrupts, so nothing calls SX2RES. The game uses its
# page 3's zeros, from FA80h to FD7Fh, and its RAM in page 0 keeps the BIOS
# away, so its hooks are unused. The patches below clear 51 bytes of them from
# FE00h for the image's code of the call: its call routine res3 and its wrapper
# at FE2Dh, which calls SX2RES and jumps to the game's routine at B2BDh.
patch page3:3E00 C9 C9 C9 C9 C9 C9 C9 C9 C9 C9 > 00 00 00 00 00 00 00 00 00 00
patch page3:3E0A C9 C9 C9 C9 C9 C9 C9 C9 C9 C9 > 00 00 00 00 00 00 00 00 00 00
patch page3:3E14 C9 C9 C9 C9 C9 C9 C9 C9 C9 C9 > 00 00 00 00 00 00 00 00 00 00
patch page3:3E1E C9 C9 C9 C9 C9 C9 C9 C9 C9 C9 > 00 00 00 00 00 00 00 00 00 00
patch page3:3E28 C9 C9 C9 C9 C9 C9 C9 C9 C9 C9 > 00 00 00 00 00 00 00 00 00 00
patch page3:3E32 C9 > 00
rescode FE00
rescall B2BD

# The title's loop calls that routine at C120h, and the game's loop at 8606h,
# once in each pass. Both call the wrapper instead.
patch page3:120 CD BD B2 > CD 2D FE
patch page2:606 CD BD B2 > CD 2D FE
