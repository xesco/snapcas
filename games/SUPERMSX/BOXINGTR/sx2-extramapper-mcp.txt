# The game is Rocky. It takes its interrupts with RET at 0038h and never reads
# the VDP's status, so after the first frame each EI gives an interrupt, 3000
# to 17000 a second, and the game runs as fast as its loops, with no frame
# clock. A call of SX2RES at each interrupt slows the game down, so the patches
# below call the wrapper at FCC9h from the game's loops, and its jump goes to
# the RET at 0038h, which returns to them.
rescall 0038
