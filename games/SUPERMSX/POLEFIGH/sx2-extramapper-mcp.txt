# The game runs without interrupts, so nothing calls SX2RES. The image's code
# for the call, its call routine res3 and its wrapper at FC79h, which calls res3
# and jumps to a RET at FC2Bh, goes to FC4Ch, in BASIC's zeros of TRPTBL, which
# the game leaves alone.
rescode FC4C
rescall FC2B

# The title waits for a key in a loop from 5F70h that reads the keyboard's
