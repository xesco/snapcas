# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Super MSX's loader `slots` finds RAM by a search that leaves slot 0's subslot
# register at 55h, RAM in page 0, when it returns with EI, so the load stopped
# right after it. It keeps BASIC's slot register value at FFFDh and the RAM's
# at FFFEh, and selects them later by the slot register again. Here the BIOS
# and the RAM share slot 0, so both values are 00h and each switch does
# nothing. The patches skip the search and make each use of the two values a
# write of slot 0's subslot register instead: 50h for BASIC and 55h for RAM in
# every page.
patch side1:71D 47 08 78 E6 > 4F 08 18 78
patch side1:799 20 DA > 18 0B
patch side1:87D 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:892 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05
patch side1:8CE 3A FD FF 20 04 D3 A8 > 3E 50 32 FF FF 18 05
patch side1:8FF 3A FE FF 20 04 D3 A8 > 3E 55 32 FF FF 18 05

# The two copies of the game's pages 0 and 1, at D000h and B500h, select the
# RAM and then BASIC with LD A,(0FFFEh) or (0FFFDh) / OUT (0A8h),A. They write
# slot 0's subslot register instead. The loader checks each block by the
# exclusive OR of its bytes, so a NOP after each RET takes the change too.
patch side1:4945 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:4955 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:495B 00 > 06
patch side1:6E8F 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:6E9F 3A FD FF D3 A8 > 3E 50 32 FF FF
patch side1:6EA5 00 > 06

# The game's start at 9850h selects BASIC the same way, and then runs Psycho

# block's exclusive OR.
