# Super MSX's loaders find RAM for pages 0 and 1 by the slot register alone, keep
# the values at FFFDh and FFFEh, and select them later by the slot register
# again. Here the BIOS and the RAM are both in slot 0, in subslots 0 and 1, so
# the patches write slot 0's subslot register instead: 54h for RAM in pages 1
# to 3, 55h for RAM in every page, 50h for BASIC, with SLTTBL's entry for slot 0
# at FCC5h where a ROM image looks up its slot, and 84h as RAM's slot ID.

# As on sx2-noexp0: the game's page 3 has no 158 free bytes from an address
# xxE1h for the tape service's part, and it keeps RAM of its own in page 0, so
# the mode without a part in page 3, whose T0 needs page 0 of DOS's mapper,
# cannot take it. So the part goes apart, in two free areas: its entries at
# DAE1h to DAFAh, and its code block at F5D1h to F654h.
service at DAE1 F5D1

# The game uses the zeros at FCC9h in page 3, where the image's wrapper for the
# call of SX2RES goes with the tape service, so nothing called SX2RES. The
# wrapper goes to FD20h, in zeros of page 3 that the game leaves alone in a
# minute of play with keys.
rescode FD20
