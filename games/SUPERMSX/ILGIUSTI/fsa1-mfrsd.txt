# Lines for fsa1-mfrsd, the Panasonic FS-A1 (MSX2, 64 KB) with a MegaFlashROM SCC+ SD
# under Nextor.

# The magazine's menu loads each program from the tape, and the game keeps
# its variables from FCE1h on, where the tape service's entries are, so the
# whole service goes into T0. T0 needs the game's page 0 RAM outside DOS's
# mapper, so the capture runs without the MegaFlashROM SCC+ SD.
capture fsa1
service t0
