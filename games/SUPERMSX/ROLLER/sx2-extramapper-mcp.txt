# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-2-1.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# After the snapshot the game writes JP 9D1Ch with LD HL,9D1Ch at 9BC3h into
# H.KEYI, over the image's call of SX2RES, which then stops. The image's wrapper
# calls SX2RES and jumps to 9D1Ch.
rescall 9D1C

# The game writes the wrapper's address, FD60h after resb at FD29h, into H.KEYI.
patch page2:1BC4 1C 9D > 60 FD
