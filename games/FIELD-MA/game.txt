# Line 130 sums the 129 bytes at A800h in an integer, to skip the BLOAD of the
# code when it is already there. openMSX starts that RAM as FFh, whose sum,
# 32895, is past an integer's 32767, so BASIC stops at "Overflow in 130". The
# patch makes the + an XOR, whose result fits, and is not the code's 11273, so
# the program loads the code.
