# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-3-0.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# Right after the restore the game writes JP 3595h at 0038h again, over the
# build's wrapper, so SX2RES was called 9 times and never again. The patch makes
# the game write the wrapper's address, FD56h after res3 at FD29h.
patch page0:3135 95 2C 36 35 > 56 2C 36 FD
