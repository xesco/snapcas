# The game writes port FEh, the ZX Spectrum's border and sound port, in two
# routines of its sound: LD A,(HL) / OUT (0FEh),A, and IN A,(0FEh) / XOR 10h /
# OUT (0FEh),A, which toggles the Spectrum's speaker. On a machine with a memory
# mapper, port FEh is the mapper's register of page 2, so page 2 shows another
# segment, the game runs into data, and the CPU loops on RST 38h. The patches
# replace each OUT (0FEh),A with LD A,A and LD D,D, which do nothing and keep
# both the sum and the exclusive OR of the block, as in Double Dragon's file.
