# The game writes port FEh, the ZX Spectrum's border and sound port, with
# OUT (0FEh),A: six times in its code, and once in each level's block, as
# XOR A / OUT (0FEh),A / LD HL,4000h. On a machine with a memory mapper, port FEh
# is the mapper's register of page 2, so page 2 shows page 3's segment 0. The
# next level's code at 9000h is then not there, and JP 9056h at EAD7h runs data
# until the CPU loops on RST 38h. The patches replace each OUT (0FEh),A with
# LD A,A and LD D,D, which do nothing and keep both the sum and the exclusive OR
# of each block, as in Mortadelo y Filemon's files.
