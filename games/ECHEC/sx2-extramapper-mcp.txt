# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The program's first BLOAD reads CODEFEN1 into FD9Ah to FFFFh. From FFCAh on,
# the block holds the bytes FFh FFh 00h 00h of an MSX1's empty memory, which
# land on an MSX2's hooks, VDP register copies and the main ROM's slot, and the
# machine resets at SCREEN 2. The patch makes the block's end address FFC9h, as
# on sx2-noexp0, so that BLOAD stops there.
patch side1:982 FF FF > C9 FF

# The program's RAM search at B6A1h tries each slot register value for pages 0
# and 1 and keeps the first that shows RAM in both. Here the BIOS and BASIC are
# in slot 0-0 and the RAM in slot 0-1, so no slot register value shows RAM
# there, and the search runs on into page 2's bits. The patch makes it return
# at once, with BASIC's slots in place.
patch side1:1D1F F3 > C9

# The program then switches pages 0 and 1 to its RAM at B6DAh, and back to BASIC
# at B6E6h, by the slot register alone. Here both are in slot 0 and differ only
# in its subslot register. The patches write that register: 55h, slot 0-1 in
# every page, and 50h, slot 0-0 in pages 0 and 1 as BASIC has it.
patch side1:1D58 3A 9F B6 F3 D3 A8 > F3 3E 55 32 FF FF
patch side1:1D64 3A A0 B6 D3 A8 > 3E 50 32 FF FF
