# Level 9's interpreter swaps between BASIC's slots and its 64 KB of RAM by the
# slot register alone, in its code and its interrupt routine. Here BASIC and
# the RAM are both in slot 0, so each swap writes slot 0's subslot register
# instead: 50h for BASIC, 55h for RAM in every page. The swaps that keep the old
# value go through small routines in the interpreter's unused bytes. The later
# versions' own RAM search, which finds no RAM by the slot register here, stores
# the two values instead.

# Each run of the interpreter's init, as at a restart, fills the vector table
# at F200h and puts JP 0EF2Eh, its interrupt routine, at F1F1h, in place of the
# vector that the build sends to its wrapper. So the image's wrapper at FD56h
# calls SX2RES and jumps to that routine, and the patches below send the
# interrupt to the wrapper.
rescall EF2E

# The init's LD HL,0EF2Eh, at EB65h, becomes LD HL,0FD56h, the wrapper.
