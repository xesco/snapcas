# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-3-0.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The loader's RAM search finds the RAM in 0-1 for pages 0 and 1 and leaves
# slot 0's subslot register at 55h. Its wrapper at B301h for TAPION, TAPIN and
# STMOTR then selects the BIOS in page 0 by the slot register alone, AND 0FCh,
# which here leaves the RAM there, and the load stopped at its first call. The
# patches make the wrapper write slot 0's subslot register instead: 54h, the
# BIOS in page 0, around the call, and 55h after it.
patch side1:10D8 DB A8 F5 E6 FC D3 A8 E1 F1 E5 > 3E 54 32 FF FF F1 00 00 00 00
patch side1:10E6 E1 F1 D3 A8 E5 > 3E 55 32 FF FF
