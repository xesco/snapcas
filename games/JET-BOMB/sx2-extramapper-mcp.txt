# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# At play the game copies JP 4578h into H.KEYI from 4575h, over the image's
# CALL resb, so SX2RES got no more calls. Its routine at 4578h drops the
# BIOS's return address and calls the hook that the game saved at 4080h. The
# image gets a wrapper that calls SX2RES and jumps to 4578h, at FD60h, and the
# template's JP 4578h becomes JP 0FD60h.
rescall 4578
patch page1:0576 78 45 > 60 FD

# Before play, and again after it, the game copies JP 4795h into H.KEYI from
# 4A3Eh, or writes RET there. The routine at 4795h returns to the BIOS's
# interrupt routine, which goes on to H.TIMI, so H.TIMI calls resb at FD29h
# too: CALL 0FD29h / RET.
patch page3:3D9F C9 8B E4 40 C9 > CD 29 FD C9 C9
