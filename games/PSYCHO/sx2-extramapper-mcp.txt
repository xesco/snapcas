# The loader's stub at 8200h, and the game's start at D391h, look for RAM in
# pages 0 and 1 by the slot register alone, and then wait forever when they
# find none: the load stopped there. They keep the slot register values for
# BASIC and for the RAM in their selectors, LD A,n / OUT (0A8h),A. Here the
# BIOS and the RAM share slot 0, so the search finds nothing. Each search
# becomes a jump or a RET, and its bytes hold two selectors that write slot
# 0's subslot register instead: 50h for BASIC, with EI, and 55h for RAM in
# every page, with DI.

patch side1:18D 0F CD 5D 82 79 F6 0A > F3 3E 55 32 FF FF C9
