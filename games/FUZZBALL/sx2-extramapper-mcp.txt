# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The game takes the interrupt in routines of its own through H.KEYI: JP 0A377h
# at the snapshot, which the image chains after its CALL resb, and JP 0D160h
# once play starts. It copies each into H.KEYI from a template, at A3C6h and
# D488h, over the image's call, so SX2RES got no more calls. The image gets a
# wrapper for each that calls SX2RES and jumps to the routine, at FD00h for
# A377h and FD06h for D160h, and the templates take the wrappers' addresses.
rescall A377 D160
patch page2:23C7 77 A3 > 00 FD
patch page3:1489 60 D1 > 06 FD
