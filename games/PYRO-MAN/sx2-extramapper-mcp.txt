# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The game runs without interrupts, so the image's call of SX2RES from H.KEYI
# never runs. A routine at FCD9h, in the zeros of SLTATR and SLTWRK, reads the
# VDP's status register 0, which the game never reads. When its bit 7 shows a
# new frame, it keeps IX, IY and the alternate registers and calls the image's
# routine at FD29h, so at most once a frame. Two entries after it call it: the
# one at FCFCh then does LD C,A / IN A,(0AAh) and returns, the one at FD03h
# jumps to the game's routine at 842Dh.
patch page3:3CD9 00 00 00 00 00 00 00 00 00 00 > F5 DB 99 07 30 1B DD E5 FD E5
patch page3:3CE3 00 00 00 00 00 00 00 00 00 00 > D9 C5 D5 E5 08 F5 08 D9 CD 29
patch page3:3CED 00 00 00 00 00 00 00 00 00 00 > FD D9 08 F1 08 E1 D1 C1 D9 FD
patch page3:3CF7 00 00 00 00 00 00 00 00 00 00 > E1 DD E1 F1 C9 CD D9 FC 4F DB
patch page3:3D01 00 00 00 00 00 00 00 00 > AA C9 CD D9 FC C3 2D 84

# The game reads each row of the keyboard through the routine at EF31h: PUSH BC
# / LD C,A / IN A,(0AAh) / ... / IN A,(0A9h) / POP BC / RET. It calls the entry
# at FCFCh in place of LD C,A / IN A,(0AAh).
patch page3:2F32 4F DB AA > CD FC FC

# Where the game waits for any key, it calls the routine at 842Dh, which scans
# the keyboard. It calls the entry at FD03h in place of that routine.
patch page2:555 CD 2D 84 > CD 03 FD
patch page2:611 CD 2D 84 > CD 03 FD
patch page2:70F CD 2D 84 > CD 03 FD
