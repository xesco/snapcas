# CasLink3's loader copies FFFFh's fields of pages 2 and 3 to pages 0 and 1 to
# load into RAM, 55h here. Its last routine gives page 0 back to the BIOS by the
# slot register alone, which leaves page 0 on the RAM in 0-1, because the BIOS
# and the RAM are both in slot 0. The patch writes 54h, the BIOS in page 0 and
# RAM in pages 1 to 3, to FFFFh and to SLTTBL's entry for slot 0 at FCC5h, from
# which ROM games find their slot, and starts the game as before.

# The game sets its stack at F380h and waits in its main loop with HALT at
# 603Dh, so each interrupt leaves 603Eh at F37Eh, right before the BIOS's
# RDPRIM at F380h, OUT (0A8h),A. The build's scan takes 3E 60 D3 A8 there for
# LD A,60h / OUT (0A8h),A and patches the return address, so the game returns
# to 003Eh and crashes. The first patch sets the stack 2 bytes lower, at
# F37Eh. The second keeps the block's sum at 9009h, which the loader checks.
