# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# CasLink3's loader copies FFFFh's fields of pages 2 and 3 to pages 0 and 1 to
# load into RAM, 55h here. Its last routine, run at F560h, gives page 0 back to
# the BIOS by the slot register alone, which leaves page 0 on the RAM in 0-1,
# because the BIOS and the RAM are both in slot 0. The game then crashes, and
# its stack writes FFFFh. The patch writes 54h, the BIOS in page 0 and RAM in
# pages 1 to 3, to FFFFh and to SLTTBL's entry for slot 0 at FCC5h, from which
# ROM games find their slot, and starts the game as before.

# The game's start at 4122h selects page 2 by RSLREG, EXPTBL and SLTTBL, but it
# takes the subslot from SLTTBL's bits of page 3 with AND 0C0h, so it selects
# 0-0, the BIOS, in page 2 in place of its own RAM in 0-1, and it resets. AND
# 0Ch takes page 1's subslot, in the bits where the slot ID keeps it: 84h here.
patch side1:39D 7E E6 C0 B1 > 7E E6 0C B1
