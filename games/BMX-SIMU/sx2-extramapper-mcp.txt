# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-3-0.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The game has two interrupt routines: C48Bh, which it installs at 0039h after
# saving the old vector at B84Ch, and A061h, which it installs at 46.8 seconds
# and which the saved vector restores. With JP 0A061h at 0038h nothing called
# SX2RES. The image's wrappers call SX2RES and jump to each: FD56h to C48Bh and
# FD5Ch to A061h, after res3 at FD29h.
rescall C48B A061

# The wrappers' addresses in the vector at 0039h, in LD HL,0C48Bh, in
# LD HL,0A061h, and in the saved vector at B84Ch.
patch page0:39 8B C4 > 56 FD
patch page3:474 8B C4 > 56 FD
patch page2:20FD 61 A0 > 5C FD
patch page2:384C 61 A0 > 5C FD
