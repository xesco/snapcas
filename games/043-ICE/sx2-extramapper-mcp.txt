# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# Right after the restore the game writes JP 5C7Dh into H.KEYI, over the
# image's CALL resb, so SX2RES got no more calls. The BIOS's interrupt routine
# still calls H.TIMI after it, where the game copies its own JP 0A160h from
# A488h, and later five RETs from A4A5h. The image gets a wrapper that calls
# SX2RES and jumps to A160h, at FD60h: the template's JP 0A160h becomes
# JP 0FD60h, and its RETs become CALL 0FD29h, a call of resb, and two RETs.
rescall A160
patch page2:2489 60 A1 > 60 FD
patch page2:24A5 C9 C9 C9 > CD 29 FD
