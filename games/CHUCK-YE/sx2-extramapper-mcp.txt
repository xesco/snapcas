# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The game takes its interrupts at 0038h in its RAM in page 0, where its routine
# calls 887Ah, so nothing called SX2RES. It also uses the zeros at FD29h and
# FCC9h, where the image's code for the call goes. The code goes to CCA0h, in
# zeros of page 3 that the game leaves alone in a minute of play with keys:
# res3, then the wrapper at CCCDh, which calls SX2RES and jumps to 887Ah, which
# returns to the routine.
rescode CCA0
rescall 887A

# The routine's CALL 887Ah at 003Eh calls the wrapper.
patch page0:3F 7A 88 > CD CC

# The game takes few interrupts, about 3 a second, so the wrapper alone calls
# SX2RES too rarely. It calls its keyboard routine at 3C78h from 3C71h about 39
# times a second. That call goes to CCD3h, after the wrapper, CALL CCA0h, res3,
# then JP 3C78h.
patch page3:CD3 00 00 00 00 00 00 > CD A0 CC C3 78 3C
patch page0:3C72 78 3C > D3 CC
