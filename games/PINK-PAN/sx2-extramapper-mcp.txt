# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The block LATCH has two routines, at 8100h and 81B5h, that find the RAM in
# 0-1 for pages 0 and 1 with their own search, which writes slot 0's subslot
# register, copy a part of the game there, and return to BASIC by the slot
# register's value from their start alone. So BASIC got back the RAM in pages
# 0 and 1. The patches write 50h, BASIC's ROM in pages 0 and 1, to FFFFh
# instead.
patch side1:37F1 3A B4 81 D3 A8 > 3E 50 32 FF FF
patch side1:38A6 3A B4 81 D3 A8 > 3E 50 32 FF FF

# The game uses the zeros at FD29h and FCC9h in page 3, where the image's code
# for the call of SX2RES goes, so nothing called SX2RES. The code goes to F870h,
# in zeros of page 3 that the game leaves alone in a minute of play with keys.
rescode F870
