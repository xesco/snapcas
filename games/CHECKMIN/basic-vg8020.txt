# Lines for the Philips VG-8020 with a Carnivore2 in slot 1.

# The capture runs without the Carnivore2, whose RAM in slot 1 the game's loader
# finds before the internal RAM in slot 3.
capture basic/vg8020-nodisk

# The game selects RAM in slot 2. The VG-8020 has its RAM in slot 3.
# LD A,0A8h / OUT (0A8h),A selects slot 2 in pages 1 to 3. The patch selects
# slot 3 there.
patch side1:FD6 3E A8 D3 A8 > 3E FC D3 A8

# LD A,0A0h / OUT (0A8h),A selects slot 2 in pages 2 and 3. The patch selects
# slot 3 there.
patch side1:FE5 3E A0 D3 A8 > 3E F0 D3 A8

# LD A,0A8h / OUT (0A8h),A selects slot 2 in pages 1 to 3. The patch selects
# slot 3 there.
patch side1:5C84 3E A8 D3 A8 > 3E FC D3 A8
