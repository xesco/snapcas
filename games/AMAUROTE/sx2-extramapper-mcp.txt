# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-3-0.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The game takes its interrupts in its own routine at 422Eh, with its stack in
# page 1, where SX2RES's entry is, so nothing called SX2RES: the image's call
# routine leaves the call out while the stack is in page 1. The game also uses
# the zeros at FD29h and FCC9h. The call's code goes to F9A0h, in zeros of page
# 3 that the game leaves alone in a minute of play with keys: res3, then the
# wrapper at F9CDh, which calls res3 and jumps to F9DDh.
rescode F9A0
rescall F9DD

# At F9D3h, LD (F9E4h),SP / LD SP,FA66h / JP F9CDh: the call runs on a stack of
# 128 bytes in the zeros up to FA66h. At F9DDh, LD SP,(F9E4h) / JP 422Eh gives
# the game its stack back and runs its routine.
patch page3:39D3 00 00 00 00 00 00 00 00 00 00 > ED 73 E4 F9 31 66 FA C3 CD F9
patch page3:39DD 00 00 00 00 00 00 00 > ED 7B E4 F9 C3 2E 42

# The jump at 0038h goes to F9D3h.
patch page0:39 2E 42 > D3 F9
