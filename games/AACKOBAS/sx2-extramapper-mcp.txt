# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30 so the game does not keep a RAM
# page in slot 3-0, which SX2RES holds.
capture sx2-extramapper-noram30

# The loader's RAM search at BC50h switches page 0 to slot 0-1 via FFFFh to
# test RAM, and its caller at BC0Dh restores only A8h, leaving page 0 on RAM
# instead of the main ROM so the return to BASIC crashes. Set RAMAD1 (F342h)
# and RAMAD0 (F341h) directly to 84h (slot 0-1) without touching FFFFh.
patch side1:3B24 26 41 CD 81 BC C0 79 32 42 > 3E 84 32 42 F3 32 41 F3 C9
