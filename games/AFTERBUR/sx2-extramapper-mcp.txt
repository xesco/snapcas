# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# The loader at F000h calls TAPION, TAPIN and STMOTR from F16Bh: it selects
# slot 0 in page 0 by the slot register alone, CALL 00xxh, and gives the slot
# register its value back. Its RAM search has put page 0 on the Extra-Mapper,
# in subslot 1 of slot 0, so the calls run RAM and the load stops after its
# first block. The patches write slot 0's subslot register instead: 54h, the
# BIOS in page 0 and RAM in pages 1 to 3, before the call, and 55h, RAM in
# every page, after it. The stack and the registers stay as the loader has
# them.
patch side1:397 DB A8 F5 E6 FC D3 A8 > F5 3E 54 32 FF FF 00
patch side1:3A4 F5 E1 F1 D3 A8 E5 F1 E1 C9 > 21 FF FF 36 55 E1 E1 C9 00

# The game loads a second copy of the same routine to CAEAh, which the
# snapshot holds where the one at F16Bh is gone, in a block that the loader
# at F000h checks by the sum of its bytes. The patches change that copy in the
# same way, and the last one gives the block's sum byte the new sum.

patch side1:E649 F5 E1 F1 D3 A8 E5 F1 E1 C9 > 21 FF FF 36 55 E1 E1 C9 00
patch side1:EC52 26 > 7B
