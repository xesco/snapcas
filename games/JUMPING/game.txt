# The game's BASIC program keeps a value at FFFFh, with POKE &HFFFF in seven
# places, and its machine code reads it with LD A,(0FFFFh). On a machine whose
# RAM is in an expanded slot, FFFFh is the slot's subslot register, and the
# first POKE deselects the RAM. The Philips NMS 8250 has no other RAM. The
# patches keep the value at FFFEh, which the game does not use.
