# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader searches page 1 for RAM with ENASLT from slot ID 80h up, 80h to
# 83h first, and finds SX2RES's mapper in 3-0 before the Extra-Mapper in 0-1,
# ID 84h. LD A,80h at E026h becomes LD A,84h, so the search starts at 0-1.
patch side1:4C 3E 80 > 3E 84

# The game builds 14 tables of 256 bytes in F200h to FFFFh, for the 7 shifts of
# a sprite's byte, and reads them with the byte as the low address. Here page 3
# is in expanded slot 0, so FFFFh is the slot's subslot register, and the last
# table's entry for FFh deselects the RAM when the game builds it. The patches,
# as for the NMS 8250, move the tables down one page, to F100h to FEFFh. The
# builder at 6A27h starts at page FEh for FFh. The lookup at 6AC4h has ADD
# A,0EFh for OR 0F0h, and steps to the second table of a pair with INC H as
# before. The game's stack, which was below F200h, is set below F100h in both
# places. The game writes nothing else in F000h to F1FFh.
patch side1:3B28 26 FF > 26 FE
patch side1:3BC5 F6 F0 > C6 EF
patch side1:113D 31 00 F2 > 31 00 F1
patch side1:11B6 31 00 F2 > 31 00 F1

# The game's image has no call of SX2RES, and the game writes over the BIOS's
# slot routines and tables in page 3. A routine at BC40h, in zeros of page 2
# that the game leaves alone, uses no BIOS routine. It keeps all the registers
# and the interrupts, selects slot 3's subslot 0 in page 1 with slot 3's subslot
# register, selects slot 3 in page 1 with the slot register, and calls SX2RES's
# entry at 4040h when it starts F5h DBh. Then it gives both registers back. The
# routine runs in page 2, because it moves pages 1 and 3. An entry at BC9Dh
# calls the routine, then does LD C,A / IN A,(0AAh) and returns.
patch page2:3C40 00 00 00 00 00 00 00 00 00 00 > F5 C5 D5 E5 DD E5 FD E5 D9 C5
patch page2:3C4A 00 00 00 00 00 00 00 00 00 00 > D5 E5 08 F5 08 ED 57 F5 F3 DB
patch page2:3C54 00 00 00 00 00 00 00 00 00 00 > A8 47 F6 C0 D3 A8 3A FF FF 2F
patch page2:3C5E 00 00 00 00 00 00 00 00 00 00 > 4F E6 F3 32 FF FF 78 E6 F3 F6
patch page2:3C68 00 00 00 00 00 00 00 00 00 00 > 0C D3 A8 C5 3A 40 40 FE F5 20
patch page2:3C72 00 00 00 00 00 00 00 00 00 00 > 08 3A 41 40 FE DB CC 40 40 C1
patch page2:3C7C 00 00 00 00 00 00 00 00 00 00 > 78 F6 C0 D3 A8 79 32 FF FF 78
patch page2:3C86 00 00 00 00 00 00 00 00 00 00 > D3 A8 F1 E2 8D BC FB 08 F1 08
patch page2:3C90 00 00 00 00 00 00 00 00 00 00 > E1 D1 C1 D9 FD E1 DD E1 E1 D1
patch page2:3C9A 00 00 00 00 00 00 00 00 00 00 > C1 F1 C9 CD 40 BC 4F DB AA C9

# The game reads each row of the keyboard through the routine at 47DBh, about 50
# times a second, in the title and in play. It calls the entry at BC9Dh in place
# of those instructions.
patch page1:7DB 4F DB AA > CD 9D BC
