# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The binary PG looks for RAM in pages 0 and 1 by the slot register alone, and
# keeps slot register values for RAM in page 1 and for BASIC at E0EBh and
# E0ECh. Here the RAM is in slot 0-1, beside the BIOS in 0-0, so the search
# finds none. The patch makes PG return at once, and the patches below select
# the RAM by slot 0's subslot register instead: 54h for RAM in pages 1 to 3,
# 50h for BASIC's ROM in pages 0 and 1.
patch side1:1D06 F3 DB A8 > C9 DB A8

# The binary RO copies itself to page 1, and then gives back BASIC's slots.
patch side1:5127 3A EB E0 D3 A8 > 3E 54 32 FF FF
patch side1:5137 3A EC E0 D3 A8 > 3E 50 32 FF FF

# The binary RA starts the game with the RAM in page 1.
patch side1:9CEB 3A EB E0 D3 A8 > 3E 54 32 FF FF
