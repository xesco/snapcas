# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The game takes the interrupt in interrupt mode 2, with its table at FE00h
# full of FDh, so that every vector is FDFDh, and JP C2DCh at FDFDh. When the
# play starts, its code at C1F5h writes the table and the jump again, over the
# image's wrapper of the vector. So the rescall line names the routine, and
# the jump at FDFDh goes to the wrapper at FD56h, which calls SX2RES and jumps
# to C2DCh, in the snapshot and in the code that writes it again.
rescall C2DC

# The snapshot's JP C2DCh at FDFDh. With the rescall line's address, the build
# leaves the table and the jump as they are.
patch page3:3DFE DC C2 > 56 FD

# LD HL,C2DCh before LD (0FDFEh),HL.
patch page3:0205 21 DC C2 > 21 56 FD
