# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# When a key starts the game, it copies JP 0D160h into H.KEYI from D488h,
# over the image's call of resb and of the same routine, so SX2RES got no more
# calls. Its routine at D160h returns to the BIOS's interrupt routine.
# The BIOS's interrupt routine still calls H.TIMI after it, so H.TIMI calls
# resb at FD29h too: CALL 0FD29h / RET.
patch page3:3D9F C9 8B E4 40 C9 > CD 29 FD C9 C9
