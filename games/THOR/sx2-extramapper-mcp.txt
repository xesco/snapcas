# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader's store of the BIOS's slot value into the handler's template, at
# 862Dh, which the new template has no place for.
patch side1:1D9 32 2D 86 > 00 00 00

# The RAM search for pages 0 and 1 tries the primary slots 0 to 3 with the slot
# register alone. The SX-2's RAM there is subslot 1 of slot 0, beside the BIOS
# in subslot 0, so the search found the mapper in slot 3-0, which SX2RES
# holds. The patch selects subslot 1 in every page of slot 0, LD A,55h /
# LD (0FFFFh),A, and takes the slot register's value as the RAM's, LD A,(84CEh) /
# LD C,A.
patch side1:1DF 06 04 21 D0 07 4F D3 A8 7E 2F 77 BE 28 06 79 C6 05 10 F2 4F > 3E 55 32 FF FF 3A CE 84 4F 00 00 00 00 00 00 00 00 00 00 00

# The loader's store of the RAM's slot value into the handler's template, at 8626h.
patch side1:1F4 32 26 86 > 00 00 00

# The loader's end selects the BIOS for BASIC's load of the next file. With one
# slot register value for both, the BIOS is subslot 0 in pages 0 and 1:
# LD A,50h / LD (0FFFFh),A.
patch side1:28E 3A CE 84 D3 A8 C9 > 3E 50 32 FF FF C9

# The interrupt handler's template, 20 bytes that the loader copies to FFDCh. It
# selected the BIOS and the RAM by the slot register. Now: CALL 0FFE7h /
# CALL 0038h / FFE2h: PUSH AF / LD A,55h / JR 0FFEAh / FFE7h: PUSH AF /
# LD A,50h / FFEAh: LD (0FFFFh),A / POP AF / RET.
patch side1:294 CD E9 FF CD 38 00 F5 3E FF D3 A8 F1 C9 F5 3E F0 D3 A8 F1 C9 > CD E7 FF CD 38 00 F5 3E 55 18 03 F5 3E 50 32 FF FF F1 C9 00

# The second file's two entries select the RAM in pages 0 and 1 after BASIC's
# load, which ran on the BIOS: subslot 1, LD A,55h / LD (0FFFFh),A.
patch side1:6044 3A 3F 9C D3 A8 > 3E 55 32 FF FF
patch side1:6079 3A 3F 9C D3 A8 > 3E 55 32 FF FF

# The game reads the BIOS's character patterns: the BIOS's subslot before the

patch side1:B10F 3A 3E 9C D3 A8 > 3E 50 32 FF FF
patch side1:B125 3A 3F 9C D3 A8 > 3E 55 32 FF FF

# Each file checks a 16-bit sum of its bytes, in CP n of its low byte and of its

patch side1:16A F9 > F0
patch side1:602C D5 > 6A
patch side1:6032 E8 > E9

# once a frame. An entry at FCFCh calls it, then does LD A,0F0h / OUT (0AAh),A
# and returns.

patch page3:3CF7 00 00 00 00 00 00 00 00 00 00 > E1 DD E1 F1 C9 CD D9 FC 3E F0
patch page3:3D01 00 00 00 > D3 AA C9
