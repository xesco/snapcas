# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The block LOADER's first routine finds the RAM in 0-1 for pages 0 and 1 with
# its own search, which writes slot 0's subslot register, copies the game to
# page 0, and returns to BASIC by the slot register's value from its start
# alone. So BASIC got back the RAM in pages 0 and 1. The patch writes 50h,
# BASIC's ROM in pages 0 and 1, to FFFFh instead.
patch side1:269 3A FF 83 D3 A8 > 3E 50 32 FF FF

# The game runs without interrupts, so nothing calls SX2RES. The image's code
# for the call, its call routine res3 and its wrapper at FD56h, which calls res3
# and jumps to a RET at FCDCh, goes to FD29h, in SLTWRK's zeros of the empty
# slots 1 and 2.
rescode FD29
rescall FCDC

# Two entries at FCC9h, in SLTATR's zeros, count their calls in the byte at
# FCF0h and call the wrapper at every 256th of the first and every 4th of the
# second. Each then does the instructions that its call replaces and returns.
patch page3:3CC9 00 00 00 00 00 00 00 00 00 00 > F5 3A F0 FC C6 01 32 F0 FC 30
patch page3:3CD3 00 00 00 00 00 00 00 00 00 00 > 03 CD 56 FD F1 DB AA E6 F0 C9
patch page3:3CDD 00 00 00 00 00 00 00 00 00 00 > F5 3A F0 FC C6 40 32 F0 FC 30
patch page3:3CE7 00 00 00 00 00 00 00 00 00 > 03 CD 56 FD F1 CD DB 22 C9

# The routine at 0163h reads a row of the keyboard, about 9500 times a second in
# the title. It calls the first entry in place of IN A,(0AAh) / AND 0F0h, about
# 35 times a second.
patch page0:165 DB AA E6 F0 > CD C9 FC 00

# The game's loop from 0288h calls the routine at 22DBh last in each pass, about
# 130 times a second. It calls the second entry instead, which calls that
# routine.
patch page0:2E7 CD DB 22 > CD DD FC
