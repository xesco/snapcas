# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game's page 3 has no 158 free bytes from an address xxE1h for the tape
# service's part, and it keeps RAM of its own in page 0, so the mode without a
# part in page 3, whose T0 needs page 0 outside DOS's mapper, cannot take it.
# Here the only RAM is that mapper. So the part goes apart, in its free bytes
# from DA48h to DB41h, as on sx2-noexp0: its entries at DAE1h to DAFAh, and its
# code block at DA48h to DACBh. These hold zeros at the snapshot, and the game
# writes none of them in a minute of play.
service at DAE1 DA48

# The game runs with the VDP's interrupt off, so the image has no call of
# SX2RES, and its stack is in page 1, which the routine gives to SX2RES. It
# calls its routine at 37D2h, DI / PUSH AF / IN A,(99h) / POP AF / EI / RET,
# about 1400 times a second in play. A routine at 8D90h, as in Knight Lore's
# file for this machine, in zeros of page 2 that the game leaves alone in a
# minute of play with keys, uses no BIOS routine. It keeps all the registers and
# the interrupts, selects slot 3's subslot 0 in page 1 with slot 3's subslot
# register, selects slot 3 in page 1 with the slot register, and calls SX2RES's
# entry at 4040h when it starts F5h DBh. Then it gives both registers back. At
# 8DEDh, the same routine, which calls 8D90h on every 32nd call, counted at
# 8E0Fh, with LD (8E0Dh),SP / LD SP,9090h before and LD SP,(8E0Dh) after: the
# call runs on a stack in zeros below 9090h.
