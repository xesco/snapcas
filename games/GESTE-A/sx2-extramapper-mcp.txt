# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the same machine without the
# 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the snapshot keeps a
# RAM page in slot 3-0, which the machine's resident program holds.
capture sx2-extramapper-noram30

# The game runs on the BIOS's interrupt routine, with the BIOS in page 0, and
# its own routine in H.KEYI, JP 0A13Ah, but the snapshot keeps its RAM page 0,
# so the image's T0 makes no call of SX2RES. The image's wrapper calls SX2RES
# through the tape service's entry code and jumps to A13Ah. sub0 takes FCC9h, so
# the wrapper goes to FB03h, in the work area of an RS-232C interface, which
# stays at zeros on the SX-2, which has none.
rescall A13A
rescode FB03

# H.KEYI jumps to the wrapper: JP 0FB03h.
patch page3:3D9B 3A A1 > 03 FB

# The build writes the wrapper's 17 bytes but, with the tape service, does not
# list them for the check, which then finds them changed. This patch changes
# nothing and lists them.
patch page3:3B03 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 > 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
