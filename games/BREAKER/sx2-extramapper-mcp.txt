# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: build.py: the snapshot keeps the RAM page 3-0-0-3.bin in slot 3-0, which
# the machine's resident program holds: the game needs RAM in another slot. `make
# games` wrote this line.
capture sx2-extramapper-noram30

# After the snapshot the game puts its own routines into H.KEYI, over the
# image's call of SX2RES, which then stops: JP 775Eh written with LD HL,775Eh at
# 777Ah, JP 43F5h written with LD HL,43F5h at 43E6h, JP 49B8h written with LD
# HL,49B8h at 4992h, and JP 5422h written with LD HL,5422h at 66A4h. The image's
# wrappers call SX2RES and jump to each routine.
rescall 775E 43F5 49B8 5422

# The game installs the wrappers' addresses instead, FD00h, FD06h, FD0Ch and
# FD12h after resb at FCC9h, as build.txt's resvector gives them, one patch for
# each writer.
patch page1:377B 5E 77 > 00 FD
patch page1:3E7 F5 43 > 06 FD
patch page1:993 B8 49 > 0C FD
patch page1:26A5 22 54 > 12 FD
