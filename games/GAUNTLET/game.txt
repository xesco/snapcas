# The main game's TAPION call goes to the service's entry. The loaders select
# the ROM in page 0 from a copy of the slot register, and the scan patches the
# first loader's calls in RAM. The main game's loader, loaded at 4400h, is in an
# unread block, so these lines patch it there.
patch side1:AE88 CD E1 00 > CD E1 FC

# The main game's STMOTR call goes to the service's entry. It stops the motor
# between the levels, which the manual tape needs to see.
patch side1:AECE CD F3 00 > CD F3 FC

# The main game's TAPIN call goes to the service's entry.
patch side1:AED4 CD E4 00 > CD E4 FC

# The block ends with a 16-bit sum of its bytes, and the 2F4h that the three
# patches add goes into it.
patch side1:E2F3 45 F0 > 39 F3
