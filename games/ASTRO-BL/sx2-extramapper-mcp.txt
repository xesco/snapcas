# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The helper that the loader loads to 8000h maps the RAM of pages 0 to 2 in
# every slot and subslot with RDSLT and WRSLT, and so selects the pages of the
# 2048 KB mapper in slot 3-0, which SX2RES holds and an image cannot keep. The
# loader takes RAMAD0 to RAMAD3, the slot of page 3 first, which here is the
# Extra-Mapper in 0-1. The patch makes the map try slot 0 alone, LD B,1 at
# 8144h, and the second keeps the block's sum, in the map's bytes at 8270h,
# which the helper fills before it reads them.
patch side1:816 06 04 > 06 01
patch side1:942 00 > 03

# The ROM image's own BIOS at E200h emulates CALSLT, and its return at E2BEh
# gives back only the slot register, which leaves page 0 on the BIOS here, where
# the BIOS and the RAM are both in slot 0. The patch jumps to a routine in dead
# code at E38Eh that also writes 55h, RAM in every page, to slot 0's subslot
# register, as in games/ALPHA87.
patch side1:5490 08 3A 71 E3 D3 A8 08 C9 > 08 3A 71 E3 C3 8E E3 00

# For a slot that is expanded, the same BIOS's copy of ENASLT calls the routine
# that writes the subslot register at A1C1h, in the game's stack, and the
# interrupt routine, which calls the BIOS's 0038h in slot 0-0, crashed. On
# sx2-noexp0 slot 0 is not expanded and the call never runs. The patch calls the
# routine's copy at E250h, in page 3, which stays in slot 0 for slot 0's
# subslots.
patch side1:54D0 CD C1 A1 > CD 50 E2

# The routine for the CALSLT return at E38Eh, in place of dead code. Its byte at
# E397h keeps the block's sum with the patches above.
patch side1:5560 F3 21 00 40 11 01 40 01 96 A3 36 C9 ED B0 C7 > D3 A8 3E 55 32 FF FF 08 C9 30 00 00 00 85 C7
