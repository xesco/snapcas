# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader at E000h first selects page 1's slot, BASIC's ROM in 0-0, in page
# 2 with ENASLT. Here that writes slot 0's subslot register and leaves no RAM
# in page 2, where the loader then copies its RAM search. Where slot 0 is not
# expanded the call writes the slot register alone, which the loader writes
# again next. The patch removes the call.
patch side1:48 CD 24 00 > 00 00 00

# The loader's two RAM searches, for page 1 and then for page 0, find the RAM
# in 0-1, but their result at FFFEh is 00h here, where the BIOS and the RAM
# share slot 0, so the loader's switches by the slot register alone do
# nothing. The patches skip both searches and make the two switches writes of
# slot 0's subslot register: 54h, RAM in pages 1 to 3, before the game's load,
# and 55h, RAM in every page, before its start at 4000h.
patch side1:D4 3A FE FF D3 A8 > 3E 54 32 FF FF
patch side1:FD 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:279 47 08 78 E6 > 4F 08 18 42
patch side1:2C9 47 08 78 E6 > 4F 08 18 3F

# The game runs without interrupts, so nothing calls SX2RES. The image's code
# for the call, its call routine res3 and its wrapper at FD56h, which calls res3
# and jumps to a RET at FCE7h, goes to FD29h, in SLTWRK's zeros of the empty
# slots 1 and 2.
rescode FD29
rescall FCE7

# The game's stack is in page 1, where SX2RES is, so res3 would leave the call
# out. An entry at FCC9h, in SLTATR's zeros, counts its calls in the byte at
# FCEAh and at every 3rd keeps the game's stack pointer, takes a stack below
# FF00h, in the BIOS's hooks, which the game's RAM in page 0 leaves unused,
# calls the wrapper and takes the game's stack back. Then it does IN A,(0AAh) /
# AND 0F0h and returns.
patch page3:3CC9 00 00 00 00 00 00 00 00 00 00 > F5 3A EA FC C6 56 32 EA FC 30
patch page3:3CD3 00 00 00 00 00 00 00 00 00 00 > 0E ED 73 E8 FC 31 00 FF CD 56
patch page3:3CDD 00 00 00 00 00 00 00 00 00 00 > FD ED 7B E8 FC F1 DB AA E6 F0
patch page3:3CE7 00 > C9

# The routine at C0D8h reads a row of the keyboard, about 100 times a second in
# the title and in play. It calls the entry in place of IN A,(0AAh) / AND 0F0h,
# about 33 times a second.
patch page3:D9 DB AA E6 F0 > CD C9 FC 00
