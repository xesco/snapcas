# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30, without the 2048 KB mapper in
# 3-0, which SX2RES holds and the loader would otherwise take.
capture sx2-extramapper-noram30

# After the load, the loader gives page 1 back with A left over from page 0's
# restore, a slot register value, which leaves page 1 on the RAM in 0-1 here.
# The patch gives page 1 page 0's slot ID from F931h, the main ROM, with H = 40h
# for the page and the same calls.
patch side1:33DF 3A 31 F9 21 00 00 CD F6 BB 21 00 40 CD F6 BB FB C9 > 3A 31 F9 60 68 F5 CD F6 BB F1 26 40 CD F6 BB FB C9

# The game uses the zeros at FD29h and FCC9h in page 3, where the image's code
# for the call of SX2RES goes, so nothing called SX2RES. The code goes to FE60h,
# in zeros of page 3 that the game leaves alone in a minute of play with keys.
rescode FE60
