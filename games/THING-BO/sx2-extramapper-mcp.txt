# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Gremlin's loader runs a RAM search at 9000h that finds the RAM of pages 0 and
# 1 in 0-1 and leaves slot 0's subslot register at 55h, RAM in page 0, when it
# returns with EI, so the next interrupt runs RAM at 0038h and the load stopped
# there. It also keeps the RAM's slot register value at FFFEh, which is 00h
# here, as BASIC's, since the BIOS and the RAM share slot 0. Each later block
# selects the RAM with LD A,(0FFFEh) / OUT (0A8h),A, and goes back to BASIC
# with AND 0F0h / OUT (0A8h),A.

# The search is skipped, as on African Trail Simulator: LD C,A / EX AF,AF' /
# JR to its end, which leaves the subslot register as it is. The loader checks
# each block by the exclusive OR of its bytes, so a NOP after the search's RET
# takes the change too.
patch side1:1C4 47 08 78 E6 > 4F 08 18 78
patch side1:249 00 > F6

# The two copies of the game's pages 0 and 1, at 8700h, select the RAM with
# LD A,55h / LD (0FFFFh),A. After the LDIR, AND 0F0h leaves 50h in A, and
# DEC BC / LD (BC),A writes it to FFFFh: BASIC again. A byte after the RET,
# which the next block loads over, keeps each block's exclusive OR.
patch side1:272 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:282 E6 F0 D3 A8 FB C9 > E6 F0 0B 02 FB C9
patch side1:288 38 > 53
patch side1:4392 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:43A2 E6 F0 D3 A8 FB C9 > E6 F0 0B 02 FB C9
patch side1:43A8 5B > 30

# The last block selects the RAM in every page and jumps to the game at 0380h.
patch side1:C5D2 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:C5DA 21 > 38
