# The level editor's code at C000h calls the MSX1 BIOS's routines at their
# own addresses, 0744h, 07CDh and 07D7h, for LDIRVM, WRTVRM and RDVRM. On an
# MSX2 those addresses hold other code: 0744h copies VRAM to RAM, so the first
# call writes 600h bytes over page 0 from 0000h, where an image with the tape
# service keeps T0, and the next interrupt crashes. The patches call the BIOS's
# jump table entries 005Ch, 004Dh and 004Ah instead, which reach the same
# routines on every MSX.
