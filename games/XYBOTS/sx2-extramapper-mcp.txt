# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The game takes its interrupts in its own routine at 7C75h, with its stack in
# page 1, where SX2RES's entry is, so nothing called SX2RES: the image's call
# routine leaves the call out while the stack is in page 1. The game also uses
# the zeros at FD29h and FCC9h. The call's code goes to F944h, in zeros of page
# 3 that the game leaves alone in a minute of play with keys: res3, then the
# wrapper at F971h, which calls res3 and jumps to F981h.
rescode F944
rescall F981

# At F977h, LD (F988h),SP / LD SP,F9FAh / JP F971h: the call runs on a stack of
# 112 bytes in the zeros up to F9FAh. At F981h, LD SP,(F988h) / JP 7C75h gives
# the game its stack back and runs its routine.
patch page3:3977 00 00 00 00 00 00 00 00 00 00 > ED 73 88 F9 31 FA F9 C3 71 F9
patch page3:3981 00 00 00 00 00 00 00 > ED 7B 88 F9 C3 75 7C

# The jump at 0038h goes to F977h.
patch page0:39 75 7C > 77 F9

# The game's stack is in page 1, the page of SX2RES's entry, and the zeros at
# FCC9h to FD88h have no room for the call's own stack. C140h holds zeros that
# the game leaves alone, so the stack goes there.
resstack C140
