# The loader's `slots` program at DDA4h looks for RAM in page 1 by the slot
# register alone. Here the BIOS and the RAM share slot 0, so it finds none,
# leaves the value at DE7Dh equal to BASIC's at DE7Eh, and the BASIC loader
# stops at "NO COMPATIBLE". The program now keeps BASIC's value and stores 54h,
# RAM in pages 1 to 3, at DE7Dh, then returns.

patch side1:24A8 32 7D DE D3 A8 > DE C3 02 DE 00

# The `carga` program selects that RAM in page 1 with LD A,(0DE7Dh) /
# OUT (0A8h),A at ACD5h. It writes 54h to slot 0's subslot register instead.
patch side1:2566 3A 7D DE D3 A8 > 3E 54 32 FF FF

# After the load, the code at AD08h moves the game up with LD DE,0FFFFh /
# LD HL,0F37Fh / LD BC,0B1E0h / LDDR. Its first byte, a byte of BASIC's work
# area, goes to FFFFh, which here is slot 0's subslot register, and it takes
# the RAM in page 1 away from the running code. The move ends at FFFEh instead
# and leaves that byte out.
