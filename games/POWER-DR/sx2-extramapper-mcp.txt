# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Page 0 is in DOS's mapper (blocking service t0) and the race buffer EA00h-FEFFh
# overwrites every xxE1h below FFE1h. Split the tape service: entries at FFE1h
# (over unused BIOS VDP copies; game never calls BIOS, neither do service/SX2RES)
# and code at FF01h-FF84h (with sub0 following in unused RET hooks).
service at FFE1 FF01

# The game uses FCC9h and keeps SP in page 1, so no automatic SX2RES hook fits.
# Place a direct-I/O SX2RES caller (slot 3-0 4040h) at 86D8h in unused page 2

# The game takes its interrupts at 0038h in its RAM in page 0, with JP EF52h.
# The jump goes to 8735h.
patch page0:39 52 EF > 35 87

# At 5 seconds the game installs 6182h with LD HL,6182h / LD (0039h),HL at
