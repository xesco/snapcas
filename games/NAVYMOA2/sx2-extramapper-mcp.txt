# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader's `slots` RAM search finds the RAM in 0-1, but its result and
# BASIC's slot register value are both 00h here, where the BIOS and the RAM
# share slot 0. The patch skips the search.
patch side1:1E51 47 08 78 E6 > 4F 08 18 78

# The block `reloc` selects the found RAM at DED1h by the slot register and
# the subslot value that the search kept, and gives the slots back to BASIC at
# DEDEh by the slot register alone. The patches write 55h, RAM in every page,
# and then 50h, BASIC, to FFFFh. The last routine then jumps to 879Bh, which in
# this dump is inside an instruction: AND D, CALL Z,0CC22h, POP DE. With slot 0
# not expanded A holds the slot register's value F0h there, so the call does
# not run. The first patch leaves F0h in A, and the second writes FFFFh through
# HL, so that A keeps it.
patch side1:1E00 3A E6 DE D3 A8 > 3E 55 32 FF FF
patch side1:1E05 3A E5 DE 32 FF FF > 3E F0 00 00 00 00
patch side1:1E0C 3A E4 DE D3 A8 > 21 FF FF 36 50
