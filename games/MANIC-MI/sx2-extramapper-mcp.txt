# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The game runs without interrupts, so the image's call of SX2RES from H.KEYI
# never runs. A routine at FCD9h, in the zeros of SLTATR and SLTWRK, keeps IX,
# IY and the alternate registers and calls the image's routine at FD29h, and
# enables the interrupts again, which that routine's RDSLT disables. An entry at
# FCF6h does BIT 7,A / RET Z, calls it, then does BIT 7,A / RET.
patch page3:3CD9 00 00 00 00 00 00 00 00 00 00 > DD E5 FD E5 D9 C5 D5 E5 08 F5
patch page3:3CE3 00 00 00 00 00 00 00 00 00 00 > 08 D9 CD 29 FD D9 08 F1 08 E1
patch page3:3CED 00 00 00 00 00 00 00 00 00 00 > D1 C1 D9 FD E1 DD E1 FB C9 CB
patch page3:3CF7 00 00 00 00 00 00 00 00 > 7F C8 CD D9 FC CB 7F C9

# The game waits for each frame with the routine at 8AFCh, which reads the VDP's
# status register 0 and ends BIT 7,A / RET, in the title and in play. It jumps
# to the entry above in place of that end, so the call runs once a frame.
patch page2:B03 CB 7F C9 > C3 F6 FC
