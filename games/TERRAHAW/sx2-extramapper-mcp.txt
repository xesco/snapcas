# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# CasLink3's loader writes an AB header at 4000h and resets the machine, so
# that the BIOS starts the game as a ROM image in RAM. That boot takes the
# 2048 KB mapper in 3-0, which SX2RES holds, for its RAM. The capture runs
# without that mapper, so the boot keeps the Extra-Mapper in 0-1.
capture sx2-extramapper-noram30

# CasLink3's loader copies FFFFh's fields of pages 2 and 3 to pages 0 and 1 to
# load into RAM, 55h here. It then gives page 0 back to the BIOS by the slot
# register alone and resets into the ROM image, which leaves page 0 on the RAM
# in 0-1, because the BIOS and the RAM are both in slot 0. The patch writes 54h,
# the BIOS in page 0 and RAM in pages 1 to 3, to FFFFh before the reset.
patch side1:1F0 F1 E6 FC D3 A8 F7 00 00 00 00 00 > F1 3E 54 32 FF FF F7 00 00 00 00
