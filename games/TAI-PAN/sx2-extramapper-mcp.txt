# The block LOADER finds the RAM in 0-1 for pages 0 and 1 with its own search,
# which leaves slot 0's subslot register at 55h, but keeps the result as slot
# register values alone, 00h here, in the operands of its routines at FA01h,
# BIOS in page 0 and RAM in page 1, and FA08h, RAM in every page, and of the
# game's at 7333h, RAM in every page, and 733Ah, the BIOS in page 0. So the
# loader called the BIOS's tape routines with RAM in page 0. The first two
# patches skip the stores of those operands, and the others make the four
# routines write 54h or 55h to FFFFh. No caller needs their AF.
