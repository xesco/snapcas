# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Gremlin's loader at D800h runs a RAM search, which finds the RAM in 0-1 but
# leaves slot 0's subslot register at 55h, RAM in page 0, and enables the
# interrupts, which then run the RAM at 0038h: the load stopped after the
# search. Its result at FFFEh, the slot register's value for the RAM, is 00h
# here, where the BIOS and the RAM share slot 0. The patch skips the search,
# so the register stays 50h, BASIC.
patch side1:1C4 47 08 78 E6 > 4F 08 18 78

# Each later block selects the RAM by that value and gives BASIC back by the
# slot register alone. The patches write slot 0's subslot register instead: 55h
# for RAM in every page, as the value at FFFEh selects elsewhere, then 50h.
patch side1:272 3A FE FF D3 A8 > 3E 55 32 FF FF
patch side1:29A DB A8 E6 F0 D3 A8 > 3E 50 32 FF FF 00
patch side1:E1F2 3A FE FF D3 A8 > 3E 55 32 FF FF

# Where a block gives BASIC back with AND 0F0h on that value and OUT (0A8h),A,
# the patches drop the block's first DI, which the loader has already done,
# move the code up a byte, and end it with LD (0FFFFh),A: 55h AND 0F0h, 50h.
patch side1:1E91 F3 3A FE FF D3 A8 01 00 40 11 > 3E 55 32 FF FF 01 00 40 11 80
patch side1:1E9B 80 03 21 80 87 ED B0 E6 F0 D3 > 03 21 80 87 ED B0 E6 F0 32 FF
patch side1:1EA5 A8 > FF
patch side1:5FB1 F3 3A FE FF D3 A8 01 00 40 11 > 3E 55 32 FF FF 01 00 40 11 00
patch side1:5FBB 00 40 21 00 88 ED B0 E6 F0 08 > 40 21 00 88 ED B0 E6 F0 08 AF
patch side1:5FC5 AF 32 00 5B 21 40 87 11 7F F8 > 32 00 5B 21 40 87 11 7F F8 06
patch side1:5FCF 06 05 1A 13 BE 23 20 07 10 F8 > 05 1A 13 BE 23 20 07 10 F8 3E
patch side1:5FD9 3E FF 32 00 5B 08 D3 A8 > FF 32 00 5B 08 32 FF FF

# The loader checks each block by the XOR of its bytes, which must be 0. The
# patches change each changed block's last byte, its sum, to keep that.
patch side1:253 0C > FA
patch side1:1E72 38 > 63
patch side1:5F92 96 > 35
patch side1:A0B2 F6 > 55
patch side1:122F2 A2 > BB

# The game takes its interrupts with RET at 0038h, in its RAM in page 0, so
# nothing called SX2RES. The image's wrapper calls SX2RES and jumps to a RET at
# 0037h. The game's stack is in page 1, the page of SX2RES's entry, where the
# call routine leaves the call out, so the calls start only with a call
# routine that takes a stack of its own.
rescall 0037

# The RET at 0037h, in FFh bytes that the game leaves alone, and at 0038h a jump
# to the wrapper, FD56h after res3 at FD29h.
patch page0:37 FF C9 FF FF > C9 C3 56 FD

# The game's stack is in page 1, the page of SX2RES's entry, and the zeros at
# FCC9h to FD88h have no room for the call's own stack. FC4Ch holds zeros that
# the game leaves alone, so the stack goes there.
resstack FC4C
