# Lines for xp800-sdmapper, the Gradiente Expert XP-800 (MSX1, 64 KB) with an SD Mapper v1.

# The game fills memory with PUSH over the tape service's part of page 3, and
# reads side 2 during play, so the whole service goes into T0. T0 needs the game's
# page 0 RAM outside DOS's mapper, so the capture runs on xp800, the Gradiente
# Expert XP-800 without cartridges.
capture xp800
service t0
