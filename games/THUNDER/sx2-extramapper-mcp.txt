# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game uses FCC9h to FD88h, so the build moves the tape service's part of
# page 3 to F0E1h, which the game then writes. At EDE1h, as on sx2, the game
# wrote the part once a key started it. The part goes to EEE1h to EF7Eh, which
# hold zeros at the snapshot and in a minute of play with keys.
service at EEE1

# The game runs with its interrupts off, so the image has no call of SX2RES, and
# its stack is often in page 1, which the routine gives to SX2RES. Its routine
# at 30CAh, DI / LD A,0F3h / OUT (0AAh),A, reads the keyboard about 8 times a
# second. A routine at 8935h, as in Knight Lore's file for this machine, in
# zeros of page 2 that the game leaves alone in a minute of play with keys, uses
# no BIOS routine. It keeps all the registers and the interrupts, selects slot
# 3's subslot 0 in page 1 with slot 3's subslot register, selects slot 3 in page
# 1 with the slot register, and calls SX2RES's entry at 4040h when it starts F5h
# DBh. Then it gives both registers back. At 8992h, DI, then LD (89A4h),SP / LD
# SP,89EEh / CALL 8935h / LD SP,(89A4h), then LD A,0F3h / RET: the call runs on
# a stack in zeros below 89EEh.
