# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game uses FCC9h to FD88h, so the build moves the tape service's part of
# page 3 to F0E1h, which the game then writes. At EDE1h, as on sx2, the game
# wrote the part once a key started it. The part goes to EEE1h to EF7Eh, which
# hold zeros at the snapshot and in a minute of play with keys.
