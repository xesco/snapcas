# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game file's service t0 puts the whole tape service in T0, which needs the
# game's page 0 RAM outside DOS's mapper. Here the only RAM is that mapper, the
# Extra-Mapper in slot 0-1. So the service keeps its part of page 3. At F9E1h,
# as on sx2-noexp0, the game wrote the part once a key started it. The entries
# go to F0E1h to F0FAh and the code to F180h to F203h, in zeros that the game
# leaves alone in a minute of play with keys.
service at F0E1 F180

# The image has no call of SX2RES: the game uses the zeros at FCC9h in page 3,
# where the image's wrapper for the call goes with the tape service, and the
# game's stack is in page 1, where the wrapper leaves the call out. A routine,
# from Knight Lore's file for this machine and in three parts, uses no BIOS
# routine, in zeros that the game leaves alone in a minute of play with keys. At
# EF68h it keeps all the registers and the interrupts and calls A69Dh, which
# with the slot register's value in B selects slot 3's subslot 0 in page 1 with
# slot 3's subslot register and slot 3 in page 1 with the slot register. It
# calls SX2RES's entry at 4040h when it starts F5h DBh, then A6B1h, which gives
# both registers back. The two parts that move page 3 are in page 2 or 2,
# outside pages 1 and 3. At EFACh, LD (EFBDh),SP / LD SP,F030h / CALL EF68h / LD
# SP,(EFBDh) / JP 9A67h: the game's stack is in page 1, which the routine gives
# to SX2RES, so the call runs on a stack in zeros below F030h.
