# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The capture runs on sx2-extramapper-noram30, without the 2048 KB mapper in
# 3-0, which SX2RES holds and the loader would otherwise take.
capture sx2-extramapper-noram30

# After the load, the loader gives page 1 back with A left over from page 0's
# restore, a slot register value, which leaves page 1 on the RAM in 0-1 here.
# The patch gives page 1 page 0's slot ID from F931h, the main ROM, with H = 40h
# for the page and the same calls.
patch side1:1DFF 3A 31 F9 21 00 00 CD F6 BB 21 00 40 CD F6 BB FB C9 > 3A 31 F9 60 68 F5 CD F6 BB F1 26 40 CD F6 BB FB C9

# The game runs without interrupts, so the image has no call of SX2RES. The
# rescode line puts the image's call routine at E940h, in zeros of page 3 that
# the game leaves alone, and the rescall line gives it a wrapper at E96Dh that
# calls SX2RES and jumps to the game's routine at F688h. The zeros at E8B2h
# after the game's table of objects are not used, because the table can grow
# there.
rescode E940
rescall F688

# In play the routine at F5E0h calls the routine at F688h about 26 times a
# second. It calls the wrapper in place of that routine.
patch page3:35E6 CD 88 F6 > CD 6D E9
