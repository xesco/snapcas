# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game's hook in H.KEYI, at 808Fh, takes over each interrupt: it drops the
# BIOS's 22 bytes from the stack, keeps the interrupted address, and goes on at
# 8103h with the registers as they are, so it takes the interrupted program's
# registers from the alternate set, IX and IY. The image calls SX2RES from
# H.KEYI before that hook, through CALSLT, which changes those registers, so
# the game hangs within 3 seconds. A routine at FD09h, in the zeros of SLTWRK,
# takes the registers from the BIOS's 22 bytes instead and goes on at 8103h,
# and H.KEYI's hook jumps there.
