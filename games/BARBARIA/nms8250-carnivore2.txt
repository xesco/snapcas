# Lines for the Philips NMS 8250 with a Carnivore2 in slot 1.

# The game copies 1B2h bytes from D974h to FF01h, a block that passes FFFFh and
# ends at 00B2h. On a machine whose RAM is in an expanded slot, FFFFh is the
# slot's subslot register, and the block's byte for it, 00h, deselects the RAM.
# The NMS 8250 has no other RAM. The first patch makes that byte AAh, the value
# that the register has when the RAM's subslot, 2, is selected in every page, so
# the write changes nothing. The game then reads 55h at FFFFh. The loader
# compares the exclusive OR of the block's bytes with the byte after the block,
# and the second patch gives that byte the value for the changed block.
patch side1:94A3 00 > AA
patch side1:9FD4 0A > A0
