# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The game is a ROM image that the loader puts in RAM in pages 1 and 2, before
# a jump to 0000h makes the BIOS's boot find it and start it. That boot tests
# SX2RES's mapper in 3-0, which the snapshot would then keep, so the capture
# runs on sx2-extramapper-noram30, without it.
capture sx2-extramapper-noram30

# The boot of the SX-2 takes longer than the second after the reset at which
# the capture takes the snapshot by itself. At 150 seconds the game runs.
snapshot at 150

# The block gui's routine at D000h copies the image's first half to page 1 with
# LD A,54h / OUT (0A8h),A, slot 1 in pages 1 to 3, and gives page 1 back to
# BASIC with LD A,50h / OUT (0A8h),A. Here BASIC and the RAM, the Extra-Mapper
# in 0-1, are both in slot 0, and 54h and 50h are slot 0's subslot register
# for these. The patch writes them to FFFFh instead, which needs the 2 unused
# bytes after the routine.
patch side1:46D6 3E 54 D3 A8 21 00 90 11 > 3E 54 32 FF FF 21 00 90
patch side1:46DE 00 40 01 00 40 ED B0 3E > 11 00 40 01 00 40 ED B0
patch side1:46E6 50 D3 A8 C9 02 FD > 3E 50 32 FF FF C9

# The image's init at 4019h selects page 2 with ENASLT, from page 1's slot and
# its byte of SLTTBL ANDed with C0h, which gives subslot 0 in every expanded
# slot. Here the image is in 0-1. AND 0Ch takes page 1's subslot.
patch side1:704 E6 C0 > E6 0C
