# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# Dinamic's RAM search starts at slot 3 and finds SX2RES's mapper in 3-0, or,
# run from page 3, cuts off its own code there. The patch starts it at slot 0,
# where it finds the Extra-Mapper in 0-1.
patch side1:3437 3E 03 > 3E 00

# After the load, the loader gives page 1 back with A left over from page 0's
# restore, a slot register value, which leaves page 1 on the RAM in 0-1 here.
# The patch gives page 1 page 0's slot ID from F931h, the main ROM, with H = 40h
# for the page and the same calls.
patch side1:33DF 3A 31 F9 21 00 00 CD F6 BB 21 00 40 CD F6 BB FB C9 > 3A 31 F9 60 68 F5 CD F6 BB F1 26 40 CD F6 BB FB C9

# The game takes its interrupts at 0038h in its RAM in page 0, with JP 0107h,
# and uses the zeros at FD29h and FCC9h in page 3, where the image's code for
# the call of SX2RES goes, so nothing called SX2RES. The code goes to EE00h, in
# zeros of page 3 that the game leaves alone in a minute of play with keys:
# res3, then the wrapper at EE2Dh for the game's routine.
rescode EE00

# The game waits for its code with the interrupts off, in a loop that calls the
# delay at 0B24h, PUSH BC / LD BC,0090h, about 7 times a second. The delay calls
# EE33h, CALL EE00h / LD BC,0090h / RET, in place of its LD BC,0090h.
patch page3:2E33 00 00 00 00 00 00 00 > CD 00 EE 01 90 00 C9
patch page0:B25 01 90 00 > CD 33 EE
