# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The block HAB3 takes the RAM's slot from page 3's slot, slot 3, slot 2 or
# else slot 1, and selects it in pages 1 to 3 by the slot register alone for
# its copy to 4000h. Here page 3 is in slot 0, so it selected the empty slot 1
# under its own stack. The first patch writes 54h, the RAM of 0-1 in pages 1
# to 3, to slot 0's subslot register, and jumps over the rest, where a routine
# now gives BASIC back with 50h. The second patch makes the block's end, POP
# AF / OUT (0A8h),A, jump to that routine.
patch side1:1CAA E6 C0 0E FC FE C0 28 08 0E A8 > 3E 54 32 FF FF 18 0C F1 3E 50
patch side1:1CB4 FE 80 28 02 > 32 FF FF C9
patch side1:1CCB F1 D3 A8 > C3 E2 87

# The block HAB4 gives page 1 page 2's slot by the slot register alone and
# starts the game in it. The patch writes 54h to FFFFh instead.
patch side1:9D46 DB A8 E6 F0 47 0F 0F B0 D3 A8 > 3E 54 32 FF FF 00 00 00 00 00

# After the snapshot the game writes JP 5A3Ah into H.KEYI, with LD HL,5A3Ah at
# 5A56h, over the image's call of SX2RES, which then stops. The image's wrapper
# calls SX2RES and jumps to 5A3Ah.
rescall 5A3A

# The game writes the wrapper's address, FD60h after resb at FD29h, into H.KEYI.
# The code is on the tape only: page 1 shows the ROM at the snapshot, and the
# writer first runs after it.
patch side1:3726 3A 5A > 60 FD
