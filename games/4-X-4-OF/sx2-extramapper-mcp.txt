# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on and SX2RES running.

# The loader at E8E9h writes JP 0E916h to 0000h of the RAM and calls it with
# CALSLT. Here the RAM is in 0-1, beside the BIOS in 0-0, so the BIOS's own
# switch of page 0 cuts off its code, and the load stopped there. The patch
# writes the same JP with page 0 selected by slot 0's subslot register, 55h,
# RAM in every page, under DI as CALSLT leaves it, and jumps to E916h.
patch side1:32 21 00 00 CD 45 EA 1E C3 CD 6B > F3 3E 55 32 FF FF 21 C3 16 22
patch side1:3C EA 23 1E 16 CD 6B EA 23 1E E9 > 00 00 3E E9 32 02 00 C3 16 E9
