# Lines for fsa1-mfrsd, the Panasonic FS-A1 (MSX2, 64 KB) with a MegaFlashROM SCC+ SD
# under Nextor.

# The game writes FD00h to FD33h, over the tape service's part of page 3, so the
# whole service goes into T0. T0 needs the game's page 0 RAM outside DOS's mapper,
# so the capture runs without the MegaFlashROM SCC+ SD.
capture fsa1
service t0
