# Lines for sx2-extramapper-mcp, the SX-2 (MSX2+, 6144 KB) with its Extra-Mapper on
# and SX2RES running.

# The capture runs on sx2-extramapper-noram30, the SX-2 with its Extra-Mapper on and
# without the 2048 KB mapper in slot 3-0. On sx2-extramapper-mcp itself the game
# fails: point 3: fail: the capture resets the machine 0.2 seconds after the
# snapshot, and the restored game does not. `make games` wrote this line.
capture sx2-extramapper-noram30

# The BASIC program's line 30 calls USR at D8B5h before line 40 loads the
# block there with BLOAD ,R, which then runs D8B5h itself. So the first call
# runs whatever the RAM holds there at power on. That is FFh here, RST 38h,
# and the game reset the machine before its load. The patch turns X=USR(T)
# into X= (T). The program does not run itself again.
patch side1:4E DD > 20
